# 视觉资产规格 · cangame

> 阶段：Phase 6 · Polish　｜　适用：Web 版 cangame　｜　维护：art-director（林绘澄）
> 目的：**固化现有视觉契约 + 约束后续新增资产**，防止体系腐化。所有新资产须对齐本规格；偏离须注明并回报。

---

## 1. 总则

- **技术前提**：纯静态 vanilla JS，零 build；所有视觉以 **CSS + 内联 SVG 字符串** 实现，**无外部图片资产**（`assets/` 无图片目录）。
- **视觉身份**：**高饱和贴纸卡通**（Quiz-App 风）= 粗黑描边 + 硬阴影 + 高饱和色块。头像为体系内的「**贴纸照片**」特例（见 §4）。
- **唯一真源**：
  - UI 色彩 → `assets/style.css` `:root` CSS 变量。
  - 头像 sub-palette → `assets/ui.js` `P_SKIN/P_HAIR/P_LIPS/P_BG/P_CLOTH` 常量。
  - 两套色板**边界清晰、不得互相引用**。

## 3. 描边 / 阴影 / 圆角语言

| token | 值 | 用途 |
| --- | --- | --- |
| **描边** | `2px solid var(--ink)`（卡片/按钮）、`2.5px`（`.card/.modal-box`）、`3px`（头像外壳，**新增**） | 统一黑描边 |
| **硬阴影** | `0 3px 0 var(--ink)`（按钮/标签，即 `--pop`） | 贴纸感来源 |
| **柔阴影** | `var(--shadow)=0 4px 0 rgba(16,15,6,.07),0 10px 24px rgba(16,15,6,.08)` | 大面板 |
| **卡片阴影** | `5px 5px 0 rgba(16,15,6,.14)` | `.card` |
| **圆角** | `--radius:20px`（卡片）、`999px`（pill/tag/dock）、`16px`（按钮）、`12–14px`（小件） | |
| **hover** | `translateY(-2px)` + 阴影加深 | 仅桌面 |
| **active** | `translateY(1px)` + 阴影变浅 | |

**规则**：任何新卡片/按钮**必须**具备 `var(--ink)` 描边 + `0 3px 0 var(--ink)` 类硬阴影，否则视为脱离体系。

## 4. 头像系统规格（`portraitSVG` / `personAvatar`）

### 4.1 契约（**不可破坏**）

1. **确定性**：`hashStr(name + '|' + gender)` 为唯一种子 → 同名同性别永远同一张脸。**禁止引入随机数/时间/STATE 依赖**。
2. **纯函数**：`portraitSVG(name, gender, age, opt)` 不读取全局，可独立渲染（QA 工具依赖此点）。
3. **无 NaN**：所有坐标须经 `Number.toFixed` 或保证为数字，QA 断言 212/212 clean 为回归门槛。
4. **uid 唯一**：渐变 id = `'pg'+(h%46657).toString(36)+((h>>>7)%89)`，**任何新增渐变必须挂同一 uid 前缀**，防串色。
5. **画布**：`viewBox="0 0 100 100"`，`width/height="100%"`，`aria-label="{name}"`。

| --- | --- | --- |

### 4.5 本次新增要求（对齐审计）

- **A-01**：承载容器加 `3px var(--ink)` 描边 + `0 3px 0 var(--ink)` 硬阴影（融入贴纸体系）。
- **A-07**：`glass` 条件补 `&& !kid`。
- 新增发型必须在 `opt.forceStyle` 0–9 枚举内并保持 `kid` 例外表同步。

## 6. 颜色冗余规则（无障碍硬约束）

> 摘自 `accessibility.md` §3，**升级为资产规格硬约束**。

**任何用颜色表达「涨/跌、正/负、好/坏、危险/安全」的视觉，必须同时具备非颜色线索**（符号 `+/−`、形状 ▲▼、文字、图案、位置至少其一）。

| 位置 | 现有冗余 | 待补 |
| --- | --- | --- |
| 市场涨跌价格 | ✅ `+/−` | — |
| 市场 shock alert | ✅ 文字 | — |
| 属性条 warn `.m.bad` | ✅ 底色+边框 | 可选补 ▼ |
| **净值/现金流正负**（`ui.js:719/720`） | ❌ 仅 `var(--red)` | **补 `+/−`** |
| **日志 `.line.money/.warn`** | ❌ 仅色 | 补前缀符号 |
| 职级 `.step.up/.on` | ✅ 位置+底色 | — |

**新增涨跌/正负 UI 一律须带符号**，否则视为不合格资产。

## 7. 无障碍约束（新资产强制）

| 要求 | 规格 |
| --- | --- |
| 正文对比 | ≥ 4.5:1；大字号(≥18.66px bold / 24px) ≥ 3:1 |
| 非文字对比（图标/边框/焦点环） | ≥ 3:1 |
| 触控目标 | ≥ 40px（目标 44px）；可用透明 padding 扩热区 |
| 焦点 | 所有可交互元素须 `:focus-visible` 可见轮廓（建议 `0 0 0 3px var(--teal-l)` 或 `var(--gold)`） |
| 动效 | 新动画须被 `prefers-reduced-motion` 降级 |
| 语义 | 装饰 emoji/SVG → `aria-hidden="true"`；纯图标按钮 → `aria-label`；动态区 `role="status"/"log"` |
| 字号 | 正文优先 `rem`；大字号模式须覆盖正文与关键数值 |

## 8. 命名与文件约定

- **无图片资产**；如未来引入：
  - 路径 `assets/img/`，命名 `{类别}-{名称}-{变体}@{倍率}.{ext}`，如 `ico-gold-coin@2x.webp`。
  - 格式：矢量优先 SVG；位图用 WebP（备 PNG）；**禁止提交 > 200KB 单图**（零 build 前提下的加载预算）。
  - 图集：同屏逻辑组 ≤ 512KB。
- **SVG 内联字符串**：函数名 `xxxSVG`，返回 `<svg viewBox="0 0 100 100" …>`，坐标保留 ≤2 位小数。
- **CSS**：新组件 class 用 `.模块-元素`（如 `.rel-card`），色/间距走变量。

## 10. 变更流程

1. 新增视觉资产 → 对照本规格 §2/§3/§6/§7 自检。
2. 触及头像 → 必须重跑 `tools/_portrait-qa.js`，确认 `212/212 clean` 且无回归。
3. 任何破坏 §4.1 头像契约的改动 → **须经主理人批准**。
4. 偏离本规格 → 在交付物中**显式标注偏离项与理由**。
