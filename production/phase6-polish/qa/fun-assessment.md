# 好玩度评估 · cangame v5.5.0（QA-01）

> 评估人：严守真　·　框架：MDA + 自我决定论(SDT) + 心流通道
> 数据支撑：`playtest-report.md`、`scripts/out/choices.md`、`out/probe.md`、`out/summary.md`
> **评估性质**：脚本模拟只能证明"系统层面是否成立"，情绪体验部分为推断，需真人试玩复核。

---

## 0. 一句话结论

**这是一款"系统层设计扎实、数值层已经崩坏"的作品。**
它给了玩家 29 条职业阶梯、241 条事件、24 种出身——自主感与关联感的骨架是完整的；
但因为**经济通胀失控 + 风险维度单向惩罚 + 评分失去区分度**，
它的胜任感（我做对了/我做错了的反馈）在 45 岁之后基本消失，
心流曲线从"挑战"直接掉进"无聊区"，并且晚年还有 8~14 年的空转。
**当前好玩度评分：5.5 / 10**（骨架值 8 分，数值与节奏扣 2.5 分）。

## 1. MDA 框架评估

### 1.1 Mechanics（机制层）—— 8/10，本作最强的一环

| 机制 | 设计质量 | 备注 |
|---|---|---|
| 29 条职业阶梯 + 4~6 级职级 | ★★★★★ | 天花板差异 1379×，"选哪条阶梯"是全作最重要的决策 |
| 中考 / 高考 + 5 道常识统考 | ★★★★☆ | 答题 + 平时分的组合有参与感；但 study 收益在 40 就封顶 |
| 61 专业 / 9 方向 + 对口求职 | ★★★★☆ | 专业真的会影响落到哪个岗位，不是装饰 |
| 24 种出身 + 家庭活账簿 | ★★★★☆ | 叙事差异 >> 数值差异，方向对，但早年代必然破产（bug） |
| 恋爱 / 婚姻 / 前任 / 复婚 / 外遇 | ★★★★★ | 关系网最完整的系统，关联感的主要来源 |
| 疾病 9 种 + 病程 4 期 | ★★★☆☆ | 机制好，但治疗费 vs 收入失衡（住院 = 2~76 年收入） |
| 市场（11 房产 / 8 车 / 9 资产 / 12 股） | ★★★☆☆ | 品类够，但房产年化 2.9% << 股票 7~10%，买房永远是错的选择 |
| 6 类贷款 + 征信 | ★★★★☆ | 网贷 4.2×利率的威慑设计得好 |
| 18 成就 / 12 彩票 / 8 向善 | ★★★☆☆ | 存在感弱，玩家很容易整局不碰 |
| 16 结局 | ★☆☆☆☆ | 74% 的局被 3 个 forceEnd 抢走，等于白做 |

**机制层结论**：广度罕见（同类产品少见 29 职业 + 24 出身 + 前任复婚），
深度也够（职业阶梯 + 病程 + 征信都在跑真数值）。
扣分项只有两个：结局系统形同虚设、房产在经济上是劣选项。

### 1.2 Dynamics（动态层）—— 4/10，这里开始崩

动态层看的是"玩家实际会形成什么策略"。模拟数据给出的实际最优解是：

> **最优策略 = 什么都别做，只做两件事：**
> **① 每年把所有闲钱买成高股息/高增长股票；② 所有事件都选风险最低的那个。**

证据：
- 稳健流的财富 93% 来自持股被动增值（见 `playtest-report.md` §1.4），
  工资结余 1.3 亿 vs 资产持有净额 18.23 亿。
- 恒选低风险的玩家 HP 从 20 岁起**常年顶格 120**、压力常年 0~4（实验 C），
  即"规避风险"零成本、零代价。
- 恒选高风险的玩家平均 30.6~36.9 岁死亡。
- 摆烂流（什么都不做）也能拿到 4136 万、85.3 岁、59% S 级。

**这三条合起来意味着：游戏只奖励一种玩法，且这种玩法不需要思考。**
玩家一旦在第 2~3 局发现"选风险低的就对了"，后续所有局都会机械执行，
241 条事件的文本差异就再也不被阅读了。

### 1.3 Aesthetics（美学层）—— 6/10

本作的目标美学显然是 **Narrative（叙事）+ Simulation（模拟）+ Fellowship（同袍之情）**，
附带一点 **Challenge（挑战）** 与 **Submission（消遣）**。

| 美学 | 达成度 | 依据 |
|---|---|---|
| 叙事 Narrative | ★★★★☆ | 文案质量高（"江景大平层""城中村隔断间"意象统一），但被高频重复事件稀释 |
| 模拟 Simulation | ★★★☆☆ | 系统多，但数值失真（房价收入比 0.6×）让"模拟中国人生"的可信度打折 |
| 同袍 Fellowship | ★★★★☆ | 父母/配偶/前任/同学/朋友/宠物七类关系 + 邀约互动，关联感强 |
| 挑战 Challenge | ★☆☆☆☆ | 买房 0.3 年搞定，26 岁达成；无任何节点构成真实门槛 |
| 发现 Discovery | ★★★☆☆ | 二周目仍有 ~50% 内容未触达，但触达是随机的、无引导的 |
| 消遣 Submission | ★★★★☆ | 点「下一年」的节奏手感好，适合碎片时间 |

**美学层的最大问题**：本作想讲"从城中村到江景大平层"的阶层跃迁故事，
但经济系统让这个跃迁在 26 岁就完成，故事的**上升段被压缩到几乎没有**，
剩下 60 年是"我已经赢了"的平铺直叙。

## 2. 自我决定论（SDT）评估

### 2.1 自主感 Autonomy —— 7/10（骨架完整，但被"唯一解"削弱）

**提供了自主感的机制（✅ 保留）**：

| 机制 | 自主性体现 |
|---|---|
| 毕业三选一（考研 / 投简历 / 休整一年） | 真的会分叉：考研成功率明示，落榜还有二战二选一 |
| 61 个专业填志愿 | 专业决定对口岗位，选择有后果 |
| 29 种职业可主动应聘 | 玩家可主动 `applyJob`，不是被分配 |
| 星探三选一（退学签约 / 要签约金 / 把书念完） | 高风险高分歧的真选择 |
| 遗产三选一（全额 / 限定 / 放弃） | 有数值含义的选择 |
| 未婚怀孕三选一 | 道德与经济双重权衡 |
| 市场自由买卖（首付比例 10%~100%） | 杠杆由玩家定 |
| 分手 / 离婚 / 联系前任 / 复合 / 复婚 | 关系完全由玩家主导 |

**削弱自主感的机制（❌）**：

1. **事件三选一的 47% 是模板生成的**（114/241 条事件没有手写选项，
   走 `eventChoices()` 的 `scaleEff(base, 0.6/1.0/1.7)` 公式，见 §4.2）。
2. **职业一旦入职基本锁死**：跨职业跳槽率只有 3%~12%，
   `autoEmploy` 只在"待业/无业"时触发，**在职状态没有任何转行通道**。
   玩家 22 岁随手选的职业，实际上决定了后面 60 年。
3. **选项文案池只有 4 组**：`CHOICE_TEMPLATES` 每个标签只有 4 组文案
   （study/work/love/money/health/family/social/risk/moral/default 各 4 组），
   一局要遇到 ~50 次模板三选一 → 同一组文案会重复出现十几次。

### 2.2 胜任感 Competence —— 3/10（本作最弱的一环）

胜任感需要「明确的挑战 → 可学的技巧 → 可见的进步 → 被承认的成就」四要素。

| 要素 | 状态 | 证据 |
|---|---|---|
| 明确的挑战 | ❌ | 买房 0.3 年攒够首付；26 岁达成；房价收入比 0.6× |
| 可学的技巧 | ⚠ | "选低风险""买股票"两条技巧一旦学会就是全部 |
| 可见的进步 | ❌ | 净资产曲线 40 岁后指数化，45 岁后玩家已无经济压力 |
| 被承认的成就 | ❌ | 稳健流 S 级 **89%**、探索流 **94%**；平均分 93.8 / 97.0 |

**评分曲线的问题（参数级）**：
```
score += min(38, sqrt(max(0, worth) / 1e8) * 3.2)     // 净资产项，满分 38
```
| 净资产（人民币） | 内部单位 | 该项得分 |
|---|---|---|
| 55.6 万 | 1e8 | 3.2 分 |
| 556 万 | 1e9 | 10.1 分 |
| 5556 万 | 1e10 | 32.0 分 |
| **7834 万** | **1.41e10** | **38 分（封顶）** |

即 **净资产项在 7834 万元就吃满 38 分**，而稳健流中位净资产 **26.14 亿 = 饱和点的 33 倍**。
加上 FAME（`min(25, FAME*0.35)`，FAME 平均 108 → 封顶 25）、
NET（`min(15, NET*0.12)`，NET 平均 163 → 封顶 15）……
**各项几乎全部封顶，总分必然趋近 100。**

**成就系统也失效**：18 个成就，探索流平均只解锁 8.9 个，随机基线 4.9 个，
且成就不参与任何经济/属性反馈，只是结局页的一排徽章。

### 2.3 关联感 Relatedness —— 8/10（本作最强的一环）

这是 v5.x 几轮迭代真正做出特色的地方，值得保留并继续加固：

| 机制 | 关联感贡献 |
|---|---|
| 父亲与你同姓 | 细节但极有效，"这是我的家" |
| 父母各有一份职业/健康/账簿，各自老去 | 让"父母"变成两个人而不是一个资源条 |
| 子女**有名有姓** + 成长阶段（蹒跚学步→上大学→长大） | 家人页一人一卡，可读性强 |
| 前任留在通讯录，可联系/复合/复婚 | 关系有"余味"，这是同类产品罕见的 |
| 配偶三种互动（陪伴/约会/送礼）+ 一年冷落只掉 1-3 点 | 婚姻要经营但不是惩罚 |
| 同学永不失联（毕业后转"老同学"） | 长线陪伴感 |
| 宠物 + 悲伤机制（grief 压心情/健康/压力） | 失去真的有代价 |
| 七类人每年主动发起邀约（inbound） | "他们会来找你"——被需要感 |

**唯一的问题**：关联感的载体（邀约事件）**频率过高**。
`confess_at` 一局触发 5.6 次、`inb_friend` 5.3 次、`inb_classmate` 4.1 次、
`inb_lover` 3.9 次、`inb_parents` 3.5 次——**这 5 个脚本事件占全部触发量的 23%**，
且它们的选项模板相同、文案池只有 4 组 → 高频 + 同质 = 从"被需要"变成"被打扰"。

## 3. 心流通道评估

心流要求「挑战难度」与「玩家能力」同步上升，始终维持在通道内。

### 3.1 实测心流曲线（稳健流）

| 年龄段 | 玩家能力（收入/资产） | 系统挑战 | 通道位置 |
|---|---|---|---|
| 0-12 岁 | 无 | 无（事件仅 9 条） | 无聊区（但节奏快，可接受） |
| 13-18 岁 | 刷题/中考/高考 | 高考分档是**真挑战** | ✅ 通道内 |
| 19-25 岁 | 专业/毕业三选一/求职 | 求职门槛（学历+属性）是**真挑战** | ✅ 通道内 |
| 26-35 岁 | 年收入 286 万，买房 | 房价 173 万 = 0.6 年收入 | ❌ **掉出通道底部（无聊区）** |
| 36-50 岁 | 净资产 6059 万 → 1.77 亿 | 无 | ❌ 无聊区 |
| 51-65 岁 | 1.77 亿 → 4.15 亿 | 无（疾病是唯一变量） | ❌ 无聊区 |
| 66-100 岁 | 8.63 亿 → 17.18 亿 | 事件仅 25 条（76+ 只有 3 条） | ❌ **无聊区 + 空转** |

### 3.2 反过来的极端（激进流 / 亡命流）

| 年龄段 | 压力 | 健康 | 通道位置 |
|---|---|---|---|
| 20 岁 | 34 | 110 | 通道内 |
| 25 岁 | **85** | 108 | ⚠ 逼近焦虑区 |
| 30 岁 | **111**（上限 120） | **69** | ❌ **焦虑区** |
| 35 岁 | 111 | **45** | ❌ 焦虑区 → 死亡 |
| 40 岁 | 114 | **35** | 死亡（平均寿命 30.6~36.9） |

### 3.3 心流诊断

- **通道太窄**：只有 13~25 岁这 12 年（中考/高考/专业/求职）处在真正的挑战区间。
  这段的设计质量也是全作最高的——说明团队知道怎么做挑战，
  只是**没有把它延伸到中年**。
- **中年（26-65）完全无挑战**：40 年游戏时长里，有 40 年处于无聊区。
- **老年（66+）是空转**：平均寿命 82~85，事件断层在 76 岁，
  玩家要空转 8~14 年。
- **高风险玩法直接跳到焦虑区且不可逆**：压力上限 120、年恢复固定 -7、无恢复手段。

## 4. 空转清单 & 伪选择清单

### 4.1 空转清单（玩家点「下一年」但无事发生）

| # | 位置 | 空转率 | 成因 | 严重度 |
|---|---|---|---|---|
| 1 | **76-100 岁** | ~100% | 事件库 76+ 只有 3 条，85 岁 2 条，90 岁 0 条 | **A** |
| 2 | **66-75 岁** | 46%~56%（整段） | 事件覆盖从 65 岁的 43 条陡降到 70 岁的 29 条 | **A** |
| 3 | **0-6 岁** | 8%（每年一次掷骰） | 覆盖事件仅 9 条 | B |
| 4 | 全年龄平均 | 11.4%~17.0% | `pickEvents` 有 65% 概率只抽 1 个事件 | C |

**量化影响**：以稳健流平均寿命 82.9 岁计算，玩家平均有 **11.6 年**是空转的，
其中 **~9 年集中在 66 岁以后**。即：**一个长寿玩家在生命的最后 20 年里，
有一半的点击是没有任何反馈的。**

**建议（参数级）**：
- 补 66-100 岁事件 **20~30 条**（退休生活/带孙辈/老友离世/慢性病管理/
  房产传承/晚年再婚/回忆杀/立遗嘱），覆盖到 95 岁。
- 或引入「晚年年度小结」卡：即使无事件，也生成一张"这一年你做了什么"的
  叙事卡（资产变化 + 家人动态 + 一句定制文案），把空转年变成节奏舒缓的收束段。
- 把 `END_AGE` 从 105 下调到 **95**，并把自然死亡风险的起始年龄从 74 提前到 **68**，
  缩短空转窗口。

### 4.2 伪选择清单

#### 伪选择 #1：模板三选一（影响 47% 的事件，共 114 条）—— **A 级**

`eventChoices()` 对没有手写选项的事件生成：

```
选项1（风险低）: eff = scaleEff(base, 0.6, 0.45),  STRESS -2
选项2（风险中）: eff = scaleEff(base, 1.0, 1.0)
选项3（风险高）: eff = scaleEff(base, 1.7, 1.35), STRESS +4, 赌注 45%
```

且赌注的期望：
- MONEY 类：`0.45 × (+1.5|M|) + 0.55 × (-0.7|M|) = +0.29|M|` → **正 EV**
- 非 MONEY 类：`0.45 × (WILL5 INT4 NET5 FAME3) + 0.55 × (HP-2 STRESS6 CHA-3)` → 正 EV

**结论**：
- 当 `base` 是正向收益时：**选项3 ≥ 选项2 ≥ 选项1**，理性玩家永远选 3。
- 当 `base` 是负向（坏事）时：**选项1 ≥ 选项2 ≥ 选项3**，理性玩家永远选 1。
- **第三个选项恒为劣势项，不存在"风险/收益权衡"，只有"按事件好坏二选一的机械判断"。**

而实际模拟中"恒选低风险"能活到 82 岁且财富最高——
说明**风险标签在现实收益上也是单向的**（见 §4.3）。

**建议**：把模板改成**真权衡**，例如：
- 选项1：稳，收益 ×1.0，代价是"错过"（如 `NET -3`、`CUR -2`）；
- 选项2：中，收益 ×1.4，附带中等概率的中等损失；
- 选项3：赌，收益 ×2.2（成功 45%）/ 损失 ×1.6（失败 55%），
  **并把 EV 调到 ≈ 选项2**，让它变成"要方差还是要稳健"的真选择，而不是"要好还是要坏"。
- 同时把 `CHOICE_TEMPLATES` 每组文案从 4 组扩到 **10 组以上**。

#### 伪选择 #2：高风险选项在系统层面单向惩罚 —— **S 级**

这不是"选项设计"问题，而是"数值设计"问题，但玩家感受上就是伪选择：
**标着"风险高"的选项，实际上没有对应的高回报，只有更高的死亡概率。**

| 风格 | 平均寿命 | 中位净资产 | 终局 HP |
|---|---|---|---|
| 恒选低风险 | 81.7 | — | 120 |
| 期望效用最大化 | 83.5 | — | 120 |
| **恒选高风险** | **35.3** | — | 35（40岁） |

压力年恢复固定 `-7`（`yearBase`: `s.STRESS = max(0, s.STRESS - 7)`），
而单个高风险选项一年可加 `+4`（risk3 固定）+ `+5~+6`（赌输）+ `+6`（硬扛生病）
+ 事件本身的压力，净增 +3~+8/年，**且没有任何对冲机制**
（向善、健身、休假都没有稳定的减压通道）。

**建议（参数级）**：
1. `yearBase` 里压力恢复改为**比例+固定**：`s.STRESS -= 7 + s.STRESS * 0.12`
   （压力越高恢复越快，避免锁死在 111）。
2. 给"高风险"以真实回报：把 `scaleEff(base, 1.7, 1.35)` 的增益系数提到 **2.4**，
   减益系数降到 **1.15**（现在是 1.7/1.35，收益不足以补偿 STRESS+4 与赌输）。
3. 增加稳定减压出口：把「运动与健身」「休假」做成**每年可用的主动行动**
   （现在健身只是大学活动之一，毕业后就没有了），`STRESS -12 / HP +4`。
4. HP 恢复：现在只有 `MOOD > 78` 时 `+1`、`STRESS < 45` 时 `+0~2`，
   应增加"年龄 < 45 且 HP < 60 时每年自然回复 +3"的基础恢复。

#### 伪选择 #3：健康/压力在保守玩法下完全无张力 —— **A 级**

恒选低风险的玩家：**HP 从 20 岁起常年顶格 120，压力常年 0~4**。
`CORE_STATS` 里 `HP` 的告警线是 `v < 30`——这个告警**永远不会亮**。
疾病系统的触发概率 `illnessRisk` 在 HP ≥ 70 时只有 0.007/年。

**结果**：保守玩家一辈子几乎不生病、不紧张、不掉血。
9 种疾病 + 4 期病程 + 治疗三选一这套**做了很重的系统，玩家根本见不到**。

**建议**：
- 提高基础压力：成年后每年有 `+3~+6` 的生活基线压力（工作/通勤/人情），
  让"压力管理"成为持续课题。
- 把 HP 上限从 120 改回 **100**，并让 `yearBase` 的自然增长在低风险下也只有
  `+0~+1`（现在 `STRESS<45` 时 `+0~2`、`MOOD>78` 时 `+1`，叠加后必然顶格）。
- 疾病触发概率在低 HP 之外增加**年龄项**：`age >= 45` 后基础概率从 0.007 提到 0.03。

#### 伪选择 #4：买房在经济上是劣选项 —— **A 级**

| 资产 | 长期年化 |
|---|---|
| 房产（`HOUSE_INDEX` 1985→2060） | **2.9%** |
| 沪深300 ETF（阻尼后） | **5.1%** |
| 华兴半导体（阻尼后） | **7.6%** |
| 智源 AI（阻尼后） | **10.5%** |

房产还要付 0.6%~1.6% 的维护费、3.5% 的交易税，
而股票只有 0.35% 手续费 + 还有分红。
→ **任何理性玩家都不该买房**，买房只是成就墙上的一个徽章。

而"从城中村到江景大平层"是本作的副标题，买房是叙事核心。
**机制与叙事互相打架**，玩家如果按最优解玩，就永远体验不到副标题承诺的故事。

**建议（参数级）**：
- `HOUSE_INDEX` 重标定：2025 从 6.9 → **12**，2060 从 10.0 → **20**
  （对应真实一线城市 2000→2025 约 8~10 倍）；
- 或给"自住房"加**非金钱收益**：`SEC +8 / MOOD +6 / 子女教育加成`，
  让买房在"人生"维度上有回报，而不只是财务维度。
- 房产的租售比（现在 5.5%~7.5%）已经不错，但被维护费 + 房价涨幅低拖累。

#### 伪选择 #5：单条事件内部的真·伪选择 —— C 级

- `eff` 全为空的：0 条。

   真人玩到第几局会腻？这是留存的核心指标，脚本完全测不了。
