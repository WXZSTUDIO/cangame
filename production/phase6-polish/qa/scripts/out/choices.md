## 4. 模板生成的三选一（eventChoices 无手写选项时的公式）

```
选项1（风险低）: eff = base × 0.6(增益) / ×0.45(减益), STRESS -2
选项2（风险中）: eff = base × 1.0 / ×1.0
选项3（风险高）: eff = base × 1.7 / ×1.35, STRESS +4, 附带 45% 概率赌注
```

赌注期望：MONEY 类 `0.45×(+1.5|M|) + 0.55×(-0.7|M|) = +0.29|M|`（正 EV）；
非 MONEY 类 `0.45×(WILL5 INT4 NET5 FAME3) + 0.55×(HP-2 STRESS6 CHA-3)`。

**结论：只要 base 是正向收益，选项3 的期望 ≥ 选项2 ≥ 选项1，理性玩家永远选 3；
只要 base 是负向（坏事），选项1 的期望 ≥ 选项2 ≥ 选项3，理性玩家永远选 1。**
即：模板三选一不是「风险/收益权衡」，而是「按事件好坏二选一的机械判断」，第三个选项恒为劣势项。
