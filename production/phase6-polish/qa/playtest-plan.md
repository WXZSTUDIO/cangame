## 1. 背景与约束

本作是**单人、文字、无社交**的人生模拟游戏，投放渠道是静态网页，没有内嵌埋点，
也没有真人玩家池可用。因此本阶段的 Playtest **不具备"真人观察"条件**，
必须改用**脚本化模拟（scripted bot playtest）+ 设计理论评估**来替代。

这一替代方案的有效性边界必须先说清楚：

| 维度 | 真人 Playtest 能测 | 脚本化模拟能测 | 脚本化模拟**不能**测 |
|---|---|---|---|
| 崩溃 / 卡死 / NaN | ✅ | ✅（更强，可跑千局） | — |
| 数值平衡 / 结局分布 | ⚠ 需大样本 | ✅（本方案核心） | — |
| 内容消耗速度 / 重复率 | ⚠ 依赖主观回忆 | ✅（可精确统计） | — |
| 文案感染力 / 情绪节奏 | ✅ | ❌ | **需人工补测** |
| UI 可读性 / 点击成本 | ✅ | ⚠ 部分（jsdom 冒烟） | 真机手感 |
| "好不好玩" | ✅ | ⚠ 只能用 MDA/SDT 推断 | **主观愉悦度** |

**结论：本轮 Playtest 只能对「系统性质量」给出 PASS/CONCERNS/FAIL 判定；
对「情感质量」只能给出风险评估，必须由主理人安排人工过一遍（真人试玩 ≥3 局）后再定级。**

## 2. 模拟方法

### 2.1 引擎注入方式

复用 `tools/_verify-v55.js` 已验证的注入模式，把 8 个模块按序注入 `vm` 沙箱：

```
assets/data.js → market.js → engine.js → school.js → career.js → love.js → loan.js → ui.js
```

- 沙箱提供 `window / document / localStorage` 桩（ui.js 需要 DOM 才不报错）。
- **关键实现细节**：现金流归因的函数包裹必须在**导出 API 之前**完成。
  否则 `vm.runInContext('({buyStock, ...})')` 拿到的是原始引用，包裹层失效，
  所有买卖现金流会被错误归到"工资结余"（v1 草稿踩过这个坑，数据完全失真）。

### 2.2 现金流归因设计

对以下函数做 AOP 包裹，按「调用前后现金差」归因，剩余部分记为工资结余：

| 包裹对象 | 归入桶 | 含义 |
|---|---|---|
| `applyEffects` | `event` | 事件/三选一直接给的钱 |
| `marketTick` | `carry` | 分红 + 租金 − 维护费 − 贷款利息 |
| `buyProp/sellProp/buyStock/sellStock/repayDebt` | `trade` | 买卖净现金流 |
| `borrow/repayLoan` | `loan` | 借贷净额 |
| `treatIllness` | `medical` | 医疗自费 |
| `buyLottery` | `lottery` | 彩票 |
| 年度现金差 − 上述之和 | `salary` | 劳动结余 |

### 2.3 玩家画像（Persona）

6 个画像，每个跑 **200 局**（共 1200 局），出生年份 / 家庭出身 / 性别全部随机。

| 画像 | 定义 | 关键行为参数 |
|---|---|---|
| **稳健流 steady** | 升学 → 对口好工作 → 存钱买房 → 定投高股息。规避风险。 | 初中高中每年刷题；中考高考选能进的最好学校；专业优先理工/金融；毕业直接工作；事件选**最低风险**；25 岁起买房（首付 50%）；余钱买高股息股；主动就医 |
| **激进流 aggressive** | 理性投机：加杠杆炒股/创业/借贷，但会治病保命。 | 考研赌一把；事件按**期望效用最大化**并偏好带赌注项；首付 10% 加杠杆；75% 现金买最高 growth 股票；能贷就贷 |
| **亡命流 reckless** | 盲目地永远点「风险高」那一个（含生病硬扛）。 | 用于验证风险-回报是否失衡 |
| **摆烂流 slacker** | 不刷题、升学走最低门槛、不理财、不主动社交，永远选最省事那个。 | 选项恒取第 1 项；从不进入市场 |
| **探索流 explorer** | 把每个系统都点一遍：校园活动/同学互动/恋爱/向善/市场/彩票，选项随机。 | 每年一项校园活动 + 同学互动 + 一件向善 + 彩票 |
| **随机基线 baseline** | 所有选项纯随机。 | 内容消耗与稳定性对照 |

### 2.4 定向实验（在主跑之外）

| 实验 | 设计 | 回答的问题 |
|---|---|---|
| **A · 阶层流动性** | 22 岁强制入职 15 种指定职业，之后统一执行稳健理财策略，每组 60 局 | 基层职业是否永远无法翻身？ |
| **B · 年代缩放** | 固定画像 + 固定出身（县城双职工），扫描出生年 1955/1965/1975/1985/1995/2005，每组 60 局 | 通胀与年代缩放是否失真？ |
| **C · HP/压力轨迹** | 4 种决策风格 × 80 局，记录 20~70 岁的 HP 与压力中位数 | 高风险到底有没有回报？健康系统是否还在起作用？ |
| **D · 选项质量静态审计** | 扫描 241 条事件的选项数、eff 差异、支配关系、年龄覆盖 | 哪些是「伪选择」？哪些年龄段内容真空？ |
| **E · 结局可达性** | 解析 ENDINGS 条件 + 统计 forceEnd 抢占比例 | 16 个结局有几个真能见到？ |

## 3. 采集指标

### 3.1 结局与评分
结局标题分布、评级 S/A/B/C/D、评分均值/标准差/最值、负资产率、平均寿命。

### 3.2 财富曲线
18/25/30/35/40/45/50/60/70/80 岁的净资产中位数 + 终局 + 峰值。

### 3.3 关键人生节点
中考/高考去向分布、30 岁职业众数、30 岁年收入与生活支出、结婚率、有娃率、
首次买房年龄与买房率、首次买股年龄、终局持股率。

### 3.4 空转与内容消耗
- **空转年**：该年 `step()` 产出的队列里**没有任何** exam / event / invest，
  玩家点「下一年」等于什么都没发生。
- 分年龄段空转率（0-12 / 13-18 / 19-25 / 26-35 / 36-50 / 51-65 / 66-100）。
- 人均事件数、人均去重事件数、事件重复率。
- 事件库触达率、Top10 事件占比、冷门事件占比。

### 3.5 现金流归因
七桶现金流，识别"钱到底从哪来"。

### 3.6 可负担性
30 岁截面：年收入 / 房价 / 房价收入比 / 年结余 / 攒够 50% 首付所需年数。

### 3.7 健康与压力轨迹
20~70 岁 HP 与压力中位数、死因分布。

## 4. 好玩度评估框架

采用三套框架交叉评估（详见 `fun-assessment.md`）：

1. **MDA**（Mechanics / Dynamics / Aesthetics）
   — 机制层看 25 个系统，动态层看玩家实际形成的策略，美学层看它到底提供了哪种乐趣。
2. **自我决定论 SDT**（自主 Autonomy / 胜任 Competence / 关联 Relatedness）
   — 逐条盘点哪些机制提供了这三类心理需求，哪些是空头的。
3. **心流通道**（挑战 vs 能力）
   — 用模拟数据判断难度曲线是走在通道里，还是掉到了「无聊区」或「焦虑区」。

并产出两张清单：
- **空转清单**：玩家点「下一年」但无事发生的年份与成因。
- **伪选择清单**：三个选项实质等价、或存在严格支配项的选项设计。

## 5. 经济平衡剖析范围

静态快照 + 动态模拟双线取证，重点回答 5 个问题：

1. 普通人能否靠正常路径买房？（房价收入比、首付攒够年数）
2. 基层职业是否永远无法翻身？（职业天花板、级差倍数、跳槽率）
3. 股市收益是否破坏经济？（股息/资本利得 vs 一辈子劳动结余）
4. 通胀与年代缩放是否失真？（HOUSE_INDEX vs FIN_SCALE vs 未缩放的工资）
5. 医疗/教育/育儿成本与人生阶段是否匹配？

所有建议必须给到**参数级**（改哪个常量、从多少改到多少），不接受"建议优化平衡"这类空话。

## 8. 已知限制（诚实声明）

1. **脚本玩家不是真人**：脚本不会读文案，不会感到惊喜/枯燥，不会在"要不要卖房救孩子"
   这种抉择上犹豫。所有关于"情绪"的结论都是**推断**，不是证据。
2. **脚本不会用 UI**：本轮全部走引擎 API，`ui.js` 的渲染、按钮可达性、移动端适配
   不在本轮范围内（另有 `tools/_dom-v55.js` 做 jsdom 冒烟，但那是回归不是 Playtest）。
3. **随机性**：所有数据基于单批次 200 局/画像。金额类指标（净资产）分布极重尾，
   中位数稳定但最高值波动大，引用"最高值"时需谨慎。
4. **市场行为的脚本化偏差**：脚本的交易策略（每年固定比例加仓）比真人更机械、也更
   纪律化，因此**股市收益的数据是"上限估计"**，真人未必能拿到这么高的复利。
