> 作者：阮和鸣（audio-director） · Phase 6 Polish · v1.0
> 适用：MVP 阶段为**纯程序化合成、无音频文件**；本文同时给出 Phase 2 引入 BGM 后的完整母线结构

## 0. 混音总纲（一句话）

> **用音区（pitch / register）承载情绪，用音量（level）只做微小的层级区分。**

这条是本份文档的核心，其余都是它的推论。

**为什么**：本作是阅读型游戏，玩家处在**安静、放松、有时是半睡半醒**的状态。任何「突然变大声」都会造成惊吓，而惊吓的结果是**玩家永久静音**——这是音频设计里唯一真正的失败。
所以我们用「低音区 + 长余韵」表达沉重，而不是「更大声」。

## 1. 母线结构（Bus Structure）

```
                               ┌─► sfxBus ──┐
oscillator / noise ──► voice ──┤            ├─► master ──► compressor ──► destination
                               └─► bgmBus ──┘                 (limiter)
```

| 节点 | 类型 | Phase 6 (SFX only) | Phase 2 (+BGM) | 说明 |
|---|---|---|---|---|
| `master` | GainNode | 0.9 | 0.9 | 总音量，留给将来可能的全局淡出 |
| `sfxBus` | GainNode | **0.80** | 0.80 | 音效总线 |
| `bgmBus` | GainNode | **0（关闭）** | 0.25 | BGM 总线。**两条总线独立**：BGM 加载失败不得影响 SFX |
| `compressor` | DynamicsCompressor | 见 §3.3 | 同 | **必须在 master 之后**，防止叠加削波 |

> ✅ **两条总线务必独立**（`audio-implementation.md` §9 的降级矩阵依赖这一点）。这是零成本但价值很高的工程决定。

## 2. 电平层级表（Relative Level）

单位：Bus 内的峰值增益相对值（0–1）。实际听感以真机校准为准。

| 层级 | 事件 | 相对参考电平 | 相对 dB | 说明 |
|---|---|---|---|---|
| **L0 心跳层** | `au.year.tick` | 0.10 | **−28 dB** | 全游戏最轻。目的是「确认系统活着」，不是「被听见」 |
| **L1 UI 层** | `au.ui.tap` `au.ui.deny` `au.card.open` | 0.14 | −25 dB | 略高于心跳，仍属「几乎注意不到」 |
| **L2 中性/兜底** | `au.result.good`／`au.result.bad` | 0.22 | **−21 dB** | **good 与 bad 电平相同**，靠滤波/音区区分 ⚠️ |
| **L3 一般事件** | `au.exam.answer` `au.trade.*` `au.love.spark` `au.loan.pay` | 0.28 | −19 dB | 明确可听，不抢戏 |
| **L4 里程碑** | `au.milestone.up` 系列（晋升/录取/结婚/生子） `au.exam.reveal` | 0.38 | −16 dB | 明显的「这件事值得记住」层 |
| **L5 负面里程碑** | `au.career.fire` `au.edu.fail` `au.family.loss` | 0.38 | **−16 dB** | ⚠️ **与 L4 持平，不要更响** |
| **L6 高优先级反馈** | `au.meta.achievement` | 0.50 | −14 dB | 全游戏最响的音之一。因为成就稀有，响一点不腻 |
| **L7 结局** | `au.meta.ending` | 0.60 | **−12 dB** | 唯一允许「充满房间」的音；唯一的例外层级 |
| **L-BGM** | BGM（Phase 2） | 峰值参考上述 SFX 峰值 **−18 dB 以下** | — | 音乐永远当背景，见 `music-direction.md` §6 |

### 2.1 三条必须遵守的层级纪律

1. **负面事件不得比正面事件响。** 沉重感由音区（低八度）+ 余韵（长尾）+ 低通（变暗）共同表达。
   > 反例：很多游戏把「受伤/失败」做得又响又炸 —— 那种设计用于动作游戏，在文字游戏里只会赶客。
2. **整个 SFX 集合的总动态跨度 ≤ 16 dB**（从最轻的 tick 到最响的 achievement）。这个窄跨度是「不惊吓」的数学保证。
3. **同层级内的事件必须做过响度归一化**。合成时请以「听起来一样响」为准逐个校准电平值，不能只填数字——不同波形的感知响度差异很大（三角波 vs 正弦 vs 噪声）。

> 📌 **校准方法（低成本）**：在同一个安静环境下，把所有音依次播放，闭眼判断；把明显突出的那个降 2–3 dB，反复两轮。比任何 LUFS 仪表更适合这个项目。

## 3. 三大混音处理器

### 3.1 低通/高通（BiquadFilter）—— 本作最主要的「情绪调色盘」

| 情绪 | 处理 | 用在 |
|---|---|---|
| 明亮、年轻、正向 | LP 截止 6–8 kHz，或加 HP 400–600 Hz「去低频让它变轻」 | `au.edu.admit` `au.love.marry` `au.family.born` |
| 中性、纸质感 | LP 4–6 kHz | `au.card.open` `au.ui.tap` |
| 阴暗、沉重 | **LP 600–1200 Hz**，并在包络内让截止频率向下滑（"关上门"的感觉） | `au.result.bad` `au.edu.fail` `au.career.fire` |
| 极重、哀悼 | **LP ≤ 800 Hz**，去掉几乎所有高次泛音 | `au.family.loss` `au.meta.ending.bad` |

> 💡 **这是「用频率而非音量做情绪」的具体执行方式。** 一个 C3 单音，LP 开到 8k 是温暖的；LP 压到 600Hz 就是棺材板上落土的闷响。**同一个合成器，零额外成本。**

### 3.2 空间感（零资产混响替代方案）

**禁止使用 ConvolverNode** —— 它需要 IR（脉冲响应）音频文件，违反 MVP 零文件原则。

**替代方案：feedback delay（反馈延迟）**

```
input ──► delay(60–120ms) ──► feedbackGain(0.25–0.35) ──┐
   │                                                     │
   └─────────────────────────────────────────────────────┘
   └──► lowpass(2–3kHz, 放在反馈环内) ──► output
```

- 反馈环内**必须串一个低通**：每一次循环都削一点高频 → 模拟真实房间的高频衰减。这是让廉价 delay 听起来像混响的关键。
- 反馈系数 **≤ 0.35**，否则会自激啸叫。
- 只给 `au.meta.ending*`、`au.family.loss`、`au.meta.achievement` 这三个「需要空间」的音加辅助送出；其余保持**完全干声**（dry）。保持干声 = 保持清晰，避免整个游戏听起来像在澡堂里。

### 3.3 压缩器（master 之后）

```
compressor.threshold = -18 dB
compressor.knee      = 12 dB     （软拐点，动作不易被察觉）
compressor.ratio     = 3:1
compressor.attack    = 0.005 s
compressor.release   = 0.25 s
```

**目的不是「让声音更有力」，而是「防止叠加削波」。**
尽管已有帧内合并 + voice cap，仍保留它作为最后一道保险（例如：快速连点未按预期合并时的临界情况）。

> ⚠️ 注意：DynamicsCompressor 会引入约 6ms 的固有延迟。对本项目（非节奏游戏）无影响。

## 4. 移动端外放混音（🔴 本节最容易被忽略，但对本项目最关键）

> **现实：本作大量玩家用手机扬声器听。** 手机小喇叭的物理限制决定了混音必须妥协——这不是「降级」，这是「按目标设备混音」。

### 4.1 手机扬声器的物理现实

| 现象 | 后果 | 对策 |
|---|---|---|
| **低于 ~400–500 Hz 严重衰减** | 任何依赖低频「厚度」的音都会消失 | 🔴 **音效主频必须落在 800 Hz – 3 kHz** |
| 单声道（mono） | 立体声宽度完全丢失 | 不要依赖 pan / stereo width 传递信息 |
| 高频指向性强、易被遮挡 | 6 kHz 以上脆弱 | 避免把「辨识度」放在 >6 kHz |
| 动态范围窄、容易失真 | 大声会破音 | 峰值进一步收 3 dB |

### 4.2 【核心规则】手机优先频率窗

> **所有 SFX 的核心辨识信息必须落在 800 Hz – 3 kHz 之间。**
> 低频（<500 Hz）只作为**存在感补充**，绝不能是唯一线索。

**具体的执行含义（直接改 `audio-implementation.md` §8 的参数表）**：

| 原设计 | 手机风险 | 修正 |
|---|---|---|
| `au.milestone.down` 单音 **C3 130.81 Hz** | 🔴 手机上几乎听不见 | **必须加一个整数倍的上方泛音/副音**（如同时发声 523 Hz C5，音量低 8 dB），由这个 523 Hz 承担「你听见了」的职责，130 Hz 只提供「沉重感」 |
| `au.family.loss` C3+G3（130/196 Hz） | 🔴 同样问题 | 同上：加一层 ~600–800 Hz 的柔和谐音层承担可闻性 |
| `au.meta.ending` C3+G3+C4 pad | 🟡 偏低 | 保留 C4（261 Hz），并加一层 C5 弱层 |
| `au.result.bad` 用 LP 1.2 kHz 压暗 | 🟡 可用但要小心 | LP 截止**不要低于 900 Hz**，否则把一个.ms Fermi 音压没了 |
| `au.ui.tap` 1800 Hz | ✅ 理想 | 无需改动 |
| `au.card.open` BP 800→3000 Hz 扫频 | ✅ 理想 | 无需改动 |

> ✅ **好消息**：`au.ui.tap` / `au.card.open` / `au.exam.answer` 这几个最常出现的「纸质感」噪声类音效，天然就落在手机的最佳频窗里。合成方案与移动端适配是**天然契合**的——这也是我推荐程序化合成的又一个理由。

### 4.3 移动端三条硬规则

| # | 规则 | 检查方法 |
|---|---|---|
| M1 | **单声道检查**：所有音在 mono 下不得消失或出现相位抵消 | 真机扬声器播放，或 DAW 里切 mono |
| M2 | **小音量检查**：把手机音量调到 20%，仍应能听见 tick/good/bad/milestone 四类 | 真机实测 |
| M3 | **外放失真检查**：音量拉到 100%，不得破音 | 真机实测 + 压缩器已在位 |

> 💡 手机扬声器还有个特性：它主要向**一个方向**辐射。玩家在床上玩时可能侧着手机。**所有关键音建议做 2–3 dB 的余量**，宁可稍响也不要听不见——因为本作的音量层级跨度已经很窄，多一点不影响「不惊吓」原则。

## 5. Phase 2 才需要的两件事（MVP 不做）

### 5.1 Sidechain Ducking（侧链闪避）

**当 BGM 上线后**，在重要 SFX 触发时对 `bgmBus` 做短促闪避：

```
触发时：bgmBus.gain: 0.25 → 0.14   (≈ −5 dB)   ramp 80ms
保持：  240 ms
恢复：  → 0.25                      ramp 400ms
```

- 只对 **优先级 ≥ 70** 的事件做（里程碑/放榜/结局/成就/丧亲）。给每个 `au.ui.tap` 都闪避 → 音乐会「抽搐」，非常难听。
- MVP 无 BGM，此项不适用。

### 5.2 屏幕状态联动音量

复用现成的 `body.dataset.screen`（`ui.js:137`）：

| dataset.screen | bgmBus 目标增益 | 说明 |
|---|---|---|
| `screen-title` | 0.30 | 标题页可稍响，这里是唯一需要「定调」的地方 |
| `screen-create` | 0.18 | 捏人需要思考，音乐退让 |
| `screen-game` | **0.25（基线）** | 主场景 |
| `screen-market` | **0.10 或淡到只剩 pad** | 计算场景必须退到几乎听不见 |
| `screen-end` | ending sting 后 → **0** | 让结局的余韵独占空间 |

**所有过渡 ≥ 1.2 秒。禁止硬切、禁止爆音。**

## 6. 验收清单（便于 QA 判定）

| # | 标准 | 判定方式 |
|---|---|---|
| X1 | SFX 总动态跨度 ≤ 16 dB | 电平表测量 tick↔achievement |
| X2 | `result.good` 与 `result.bad` 听感响度相当（差 ≤ 1.5 dB） | 盲听对比 |
| X3 | 负面事件不比正面事件响 | 同上 |
| X4 | 所有音在手机扬声器（>800 Hz 成分存在）可闻 | 真机 M1/M2/M3 |
