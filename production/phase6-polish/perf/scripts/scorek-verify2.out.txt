## 两处反转的细节

### 反转 A：二本 / 一本（design-strategist 发现的那个）

- 选择反转窗口：gao ∈ **[476, 479]**（共 4 分）
  → 这段里玩家**够得上一本**，但二本封顶的 1.0450 更高
- 更广义的「分数提高反而变差」窗口：gao ∈ [462, 479]
  → 462 分起二本就吃满 0.95×1.10 = 1.0450；476 分能上一本了却只有 1.0400

### 反转 B：落榜 / 专科（**E-12 要防的那个，我独立扫出来做了交叉验证**）

- 窗口：gao ∈ **[294, 318]**（共 25 分）

- **→ 落榜比上专科更划算，与叙事语义完全相反。E-12 必须做，不是可选优化。**

> ⚠ 余量只有 1.4%。**这个修正是「刚好够」，不是「有富余」**：
> 任何人以后把二本 `salaryK` 从 0.95 抬到 0.96（仍在安全线内），或把一本 `minScore` 改了，反转会**静默回归**。
> **所以必须配一条回归断言**：全档位单调性检查（下面 §3），否则这个 1.06 是个定时炸弹。

## 建议的回归断言（可脚本化，零噪声）

```js
/* 不变量：任意 gao 下，「更差档的实际 salaryK」不得严格大于「更好档」 */
function assertSalaryKMonotonic() {
  for (let i = 0; i < UNIVERSITIES.length - 1; i++) {
    const better = UNIVERSITIES[i], worse = UNIVERSITIES[i + 1];
    if (worse.id === 'u_fail') continue;              // E-12：落榜档不参与
    for (let g = 0; g <= 700; g++) {
      if (g < uniNeed(better)) continue;
      if (salaryKFor(worse, g) > salaryKFor(better, g) + 1e-9) {
        throw new Error('档位反转: gao=' + g + ' ' + worse.name + ' > ' + better.name);
      }
    }
  }
}
```
