每格 400 局，共 1600 局。四个格子用**同一个随机序列**推进，唯一差异是画像与 `cramCap`。

## 1. 先摆事实：两个画像差在哪

- `steady`（稳健流）：jobTarget = [ai,doctor,finance,programmer,civil,teacher,accountant,lawyer,pm,designer,nurse,ecom,clerk]，social = **moderate**，market = house_first，cram = true
- `explorer`（探索流）：jobTarget = [**空**]，social = **full**，market = balanced，cram = true

`jobTarget` 为空 ⇒ `doPlayerActions` 里 `p.jobTarget && p.jobTarget.length` 为假 ⇒ **从不主动应聘**，职业全靠事件系统派发。
`social: 'full'` ⇒ 每年调 `doUniActivity()` + `classmateAct()`，`classmateAct` 每次 +2 NET。
`social: 'moderate'` ⇒ 这两个都**一次都不调**。
