## 4. 首屏关键路径
```
  HTML 下载+解析  ──┐
  CSS 下载(6.5KB gz)─┤ 并行
  8×JS 下载(预防扫描并行) ─┘  最慢的一项决定下限： data.js 52.6 KB gzip
        ↓
  按序执行 8 个脚本（阻塞渲染）  ← 本次实测 9.9 ms（桌面）
        ↓
  DOMContentLoaded → init() → renderTitle() → 首屏可见
```
结论：CPU 侧（编译+执行）不是瓶颈，**网络 + 串行阻塞才是**——在 3G/弱网（≈400 kbps 有效）下，光 data.js 的 52.6 KB 就要 ~1.0 s；而这段时间内页面是白屏的，因为 8 个 `<script>` 没有一个 `defer`。
