## 0. 结论先行

> ### 假设**不成立**。
>
> **补习不会让收入腰斩，它的真实效应是「增收 +25% ~ +55%」。**
> 那个 −52% **不是游戏机制问题，是测量工具的混淆**：
> REG-11 的循环里 `pn`（画像）与 `cap`（补习预算）**完全共线**，
> 所以「补习组 vs 不补习组」实际上是「explorer 画像 vs steady 画像」。
>
> 交叉验证：画像效应 **−61.7%** × 补习效应 **+25.2%** = **−52.1%**，
> 与原口径实测的 **−52.1%** 完全吻合 —— 数字对得上，说明归因没有残留。
>
> 但 quality-lead 有**一半是对的**：「高考提分确实有效」这部分成立（+44~+52 分）。
> 错的是把画像差当成了补习的代价。

**给 design-strategist 的一句话**：补习系统**不需要削弱、更不需要废除**；
它真正的设计缺陷是**收益一次性跳变、之后归零、且几乎没有长期代价**——
玩家过了大学档线之后，再刷题是纯无意义操作。这是**机制问题**，不是数值问题。

## 1. 假设的三重反证

quality-lead 的假设：*补习占用了社交/人脉类行动 → NET 属性被压低 → 伤到 `careerIncome()` 里的 `(1+NET/1000)` 项。*

### 反证 ①：机制上不可能 —— 补习根本不碰 NET

`assets/school.js:473-482` 原文：

```js
function cramSchool(state) {
  if (state.age >= EXAM_META.gaoAge || state.age < 7) return { ok: false, msg: '现在不用刷题' };
  const touch = state.uniTouch = state.uniTouch || {};
  if (touch.cram === state.age) return { ok: false, msg: '今年已经刷过了' };
  touch.cram = state.age;
  state.edu.study = clamp((state.edu.study || 0) + randInt(6, 11), 0, EXAM_META.studyCap);
  applyEffects(state, { INT: randInt(2, 4), HP: -3, STRESS: 5, GROW: 2 });
  pushLog(state, `【刷题】...`);
  return { ok: true };
}
```

效应是 `{INT: +2~4, HP: −3, STRESS: +5, GROW: +2}` —— **五个字段里没有 NET**。

### 反证 ②：生命周期不重叠 —— 物理上无法竞争

| 行动 | 触发条件 | 年龄段 |
|---|---|---|
| `cramSchool` | `age >= 13 && age < EXAM_META.gaoAge` | **13 ~ 17** |
| `doUniActivity` | 需要 `st.edu.uni && st.edu.uni !== 'u_fail'` | **18+**（大学） |
| `classmateAct` | 任意（有同学即可） | 任意 |

补习在**中学**，大学社交活动在**大学**。两者**不在同一年发生**，不存在「挤占」。

### 反证 ③：代码里没有行动配额，只有独立 `if`

`reg-sim.js:114-128` 的 `doPlayerActions()`：

```js
if (p.cram && st.age >= 13 && st.age < A.EXAM_META.gaoAge && (st.edu.study||0) < ...) {
  A.cramSchool(st);                                    // ← 独立 if
}
if (p.social === 'full' && st.edu.uni && ...) {
  A.doUniActivity(st, acts[rnd(acts.length)]);         // ← 独立 if，不是 else if
}
if (p.social === 'full' && st.classmates.length) A.classmateAct(st, ...);  // ← 又一个独立 if
```

**是并列的 `if`，不是 `else if`，也没有共享的行动点预算。**
刷题与否，对后面两个分支**没有任何影响**。

> 补充：真正的因果方向甚至与假设**相反** —— `careerTick()` 晋升时会 `applyEffects({LOY: +6, NET: +3, ...})`
> （`career.js:532`）。在这套数值里，**职业成功会产出人脉，而不是消耗人脉**。

## 2. 真因：实验装置的共线性

`regression-run.js:370-374`（REG-11 的取样循环）：

```js
const pool = ['steady', 'explorer'];
for (let i = 0; i < n; i++) {
  const pn  = pool[i % pool.length];      // pool.length === 2
  const cap = (i % 2 === 0) ? 0 : 40;
  ...
}
```

| i | `i % 2` | `pn = pool[i % 2]` | `cap` |
|---|---|---|---|
| 偶 | 0 | **steady** | **0** |
| 奇 | 1 | **explorer** | **40** |

**`pn` 与 `cap` 严格一一对应，零自由度。** 于是：

- 「低投入组」= **100% steady**，从不补习
- 「高投入组」= **100% explorer**，补习到上限

而这两个画像在职业维度上差异极大（`reg-lib.js:59-93`）：

| 字段 | `steady`（稳健流） | `explorer`（探索流） |
|---|---|---|
| `jobTarget` | **13 个**：ai / doctor / finance / **programmer** / civil / … / **ecom** / clerk | **空数组** |
| `social` | `moderate` | `full` |
| `market` | `house_first` | `balanced` |

- `jobTarget: []` ⇒ `p.jobTarget && p.jobTarget.length` 为假 ⇒ **从不主动应聘**，职业全靠事件系统随机派发 ⇒ 大量落到 `clerk`（公司文员，3 级年薪 0.56 亿，是全表最低档之一）。
- `social: 'full'` ⇒ 每年调 `doUniActivity()` + `classmateAct()`，后者每次 **+2 NET**，四年大学累积上百点。
- `social: 'moderate'` ⇒ 这两个分支**一次都不执行**。

**这就是 NET 70 → 190 的全部来源**，与补习无关。

## 3. 2×2 因子实验：决定性证据

把两个因子拆成正交设计：每画像 × 每 cap，每格 400 局（共 1600 局），四格共用同一随机序列推进。

| 画像 | cramCap | 局数 | studyAt18 | 高考分 | 30 岁收入 | 主落点 |
|---|---|---:|---:|---:|---:|---|
| steady | 0 | 376 | 0 | 497 | 4.24 亿 | ecom |
| steady | 40 | 372 | 31 | 541 | 5.31 亿 | programmer |
| explorer | 0 | 381 | 0 | 482 | 1.62 亿 | clerk |
| explorer | 40 | 370 | 31 | 528 | 2.03 亿 | clerk |

**主效应 vs 画像效应：**

| 对比 | 口径 | 收入变化 |
|---|---|---:|
| 同画像内 `cramCap 0 → 40`（steady） | **真正的补习效应** | **+25.2%** |
| 同画像内 `cramCap 0 → 40`（explorer） | **真正的补习效应** | **+25.0%** |
| 同 cap 内 `steady → explorer`（cap=0） | 画像效应 | **−61.7%** |
| 同 cap 内 `steady → explorer`（cap=40） | 画像效应 | **−61.8%** |
| 原 REG-11 口径（steady@0 vs explorer@40） | 两者混在一起 | −52.1% |

**交叉验证**：`0.383 × 1.252 = 0.4795` → **−52.05%**，实测 **−52.1%**。
两个效应相乘能精确还原原口径，说明归因完整、没有第三个因素。

**属性对照（同画像内，补习前后的真实差异）：**

| 画像 | cramCap | NET 中位 | CHA 中位 | INT 中位 | STRESS 中位 |
|---|---|---:|---:|---:|---:|
| steady | 0 | 69.0 | 22.5 | 130.6 | 3.0 |
| steady | 40 | 68.0 | 22.1 | **148.0** | 3.0 |
| explorer | 0 | 193.6 | 96.9 | 147.9 | 12.0 |
| explorer | 40 | 193.2 | 98.3 | **164.7** | 12.5 |

**NET 在画像内纹丝不动（−1.0 与 −0.4，纯噪声）**，动的只有 INT（+17.4 / +16.8）——
正是 `cramSchool` 的 `INT: +2~4` × 5 次。这与源码完全对得上。

## 4. 收入公式逐项分解

用 IMP-01 落地的 `careerIncomeParts()` 把 `careerIncome = base × kAge × kEdu × kInt × kNet × kLoy` 拆开。

**原（混淆）口径下**，五个乘子的走向：

| 因子 | 不补习(steady) | 补习(explorer) | 变化 |
|---|---:|---:|---:|
| base（职称年薪基数） | 1.90 亿 | 0.82 亿 | **−56.8%** |
| kAge | 1.22 | 1.22 | +0.0% |
| kEdu | 1.04 | 1.20 | **+15.4%** |
| kInt | 1.25 | 1.32 | +5.3% |
| kNet | 1.07 | 1.19 | **+11.3%** |
| kLoy | 1.02 | 1.03 | +1.5% |
| **total** | 3.25 亿 | 1.67 亿 | −48.7% |

**注意 kNet 是 +11.3%，方向为正。** 假设 predicts 它应该为负。

### NET 项到底有多大的权重（回答任务书第 2 问）

`kNet = 1 + NET / 1000`（`CAREER_MULT.stats.NET = 1000`）。
在 30 岁典型 NET ≈ 70 的区间里：

| NET | kNet | 年薪相对变化 |
|---:|---:|---:|
| 70 | 1.070 | 基准 |
| 50 | 1.050 | −1.9% |
| 30 | 1.030 | −3.7% |
| 0 | 1.000 | −6.5% |
| −100 | 0.900 | −15.9% |
| −200 | 0.800 | −25.2% |
| −390 | 0.610 | −43.0% |

**反解**（`NET' = (1 − t/100) × (1000 + NET) − 1000`）：

| 想让年薪掉 | NET 需要从 70 掉到 | Δ NET |
|---:|---:|---:|
| 10% | −37 | −107 |
| 20% | −144 | −214 |
| 30% | −251 | −321 |
| **39%** | **−347** | **−417** |
| **52%** | **−486** | **−556** |

> **结论**：要让年薪掉 39%~52%，NET 必须跌到 **−347 ~ −486**。
> 而 NET 是 `clamp` 在 0~100 的属性，**物理上不可能为负到这个量级**。
> 即便 NET 从 70 一路清零，年薪也只掉 **6.5%**。
> **NET 项在数学上就不可能解释 39%~52% 的收入跌幅 —— 假设的分母就错了。**

## 5. 补习的真实收益：剂量-反应曲线

自变量 `cramCap`（学习投入上限）。`cramSchool` 每次 +6~11，13~17 岁每年一次，最多 5 次。

**`steady`（稳健流）**

| cramCap | studyAt18 | 高考分 | salaryK | 30岁收入 | 相对 cap=0 | 边际 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 0 | 501 | 1.04 | 3.63 亿 | — | — |
| **10** | **15** | 525 | 1.04 | 4.98 亿 | **+37.0%** | **+37.0%** |
| 20 | 24 | 529 | 1.04 | 5.22 亿 | +43.8% | +6.8% |
| 30 | 30 | 544 | 1.04 | 5.21 亿 | +43.4% | −0.4% |
| 40 | 30 | 542 | 1.04 | 5.25 亿 | +44.6% | +1.2% |
| 60 | 30 | 538 | 1.04 | 5.25 亿 | +44.5% | −0.0% |
| 100 | 31 | 538 | 1.04 | 5.27 亿 | +44.9% | +0.1% |

**`explorer`（探索流）**

| cramCap | studyAt18 | 高考分 | salaryK | 30岁收入 | 相对 cap=0 | 边际 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 0 | 476 | 1.04 | 1.63 亿 | — | — |
| **10** | **15** | 504 | **1.20** | 2.03 亿 | **+24.8%** | **+24.8%** |
| 20 | 24 | 520 | 1.20 | 2.00 亿 | +22.7% | −2.0% |
| 30 | 30 | 519 | 1.20 | 2.00 亿 | +22.7% | −0.1% |
| 40 | 31 | 519 | 1.20 | 1.96 亿 | +20.6% | −2.1% |
| 60 | 30 | 521 | 1.20 | 2.03 亿 | +24.6% | +2.0% |
| 100 | 31 | 528 | 1.20 | 1.56 亿 | −4.1% | −7.2% |

**读法**：

1. **全部收益集中在前 ~15 点 study（约 2 次补习）**。之后 study 15 → 31（再刷 2~3 次）收益为 **0**。
2. `explorer@100` 的 −4.1% 是**噪声**：三轮独立复跑（每格 400 局 × 3）显示 explorer 的收入中位数
   摆动幅度达 **30.8%**，远大于不同剂量之间的差异（~5%）。**不存在「投过头反而亏」的拐点。**
3. `steady` 三轮复跑：cap=0 得 4.60/3.34/3.85，cap=40 得 5.20/5.26/5.24 → **+33.0%**，与 2×2 的 +25.2% 同向。

**三个口径汇总**：2×2 因子 **+25.2% / +25.0%**；剂量实验 **+44.9%**；三轮复跑 **+33.0%**。
→ 保守表述：**补习的真实效应是增收 +25% ~ +45%**。

## 6. 收益从哪来：完整因果链

```
cramSchool()
  ├─ study +6~11/次           → gaoExamScore: study × 0.20
  └─ INT +2~4/次（×5 ≈ +17）  → gaoExamScore: INT  × 0.40   ← 提分的一半来自这里
                                        ↓
                              高考分 +44 ~ +52（满分 700）
                                        ↓
                     跨过大学录取线（一本 476 → 211 546，985 616）
                                        ↓
        ┌───────────────────────────────┴───────────────────────────────┐
        ↓                                                               ↓
  salaryK 1.04 → 1.20                                    专业池改变 → 解锁「理工」门控
  （kEdu +15.4%）                                        （programmer / hacker / ai）
        ↓                                                               ↓
  careerTick 晋升分 +3.5                                   落到更高薪阶梯（base ↑）
  （公式里 (salaryK−1) × 22）
```

### 关键数值

**高考分公式**（`school.js:229-247`）：
```
sc = 52 + (INT−55)×0.40 + (WILL−35)×0.12 + study×0.20 + hs.gaoBonus
   + tutor(0/4/7) + rand(−11,11) − max(0,STRESS−45)×0.30 − poor(0/6) − in_love?8
```
满分 700，其中平时分是 **sqrt 曲线**（`academicBase = round(sqrt(raw/ceil) × academicPart)`，`school.js:307`）
→ **raw 越高，边际转换效率越低**，这是天然的边际递减。

**大学录取线**（`need = round(minScore/100 × 700)`，`school.js:264`）：

| 学校 | 录取线 | salaryK | 专业池 |
|---|---:|---:|---|
| 985 重点 | 616 | 1.42 | 计算机、人工智能、金融学、临床医学、法学、电子信息 |
| 211 大学 | 546 | 1.20 | 软件工程、会计学、新闻学、机械、教育学、播音与主持艺术 |
| 普通一本 | 476 | 1.04 | 工商管理、土木工程、英语、市场营销、视觉传达设计、表演 |
| 二本/民办 | 392 | 0.95 | 电子商务、国贸、环境工程、汉语言文学、动画、音乐表演 |

**职业入职门槛**（`jobOffers()`，`career.js:450-473`）：

| 职业 | 属性门槛 | 专业对口 | 0 级年薪 | 3 级年薪 |
|---|---|---|---:|---:|
| AI 算法工程师 | INT≥65 | 理工 | 0.70 亿 | 5.00 亿 |
| 黑客 / 安全研究员 | INT≥55 | 理工 | 0.36 亿 | **3.00 亿** |
| 投行 / 券商 | INT≥55、CHA≥35 | 金融 | 0.50 亿 | 4.00 亿 |
| 程序员 | INT≥40 | 理工 | 0.30 亿 | 1.20 亿 |
| 电商运营 | INT≥28 | 金融/理工 | 0.22 亿 | 1.40 亿 |
| 公司文员 | 无 | 金融/师范 | 0.16 亿 | 0.56 亿 |

**⚠ 值得设计侧注意**：`普通一本` 的专业池里**没有一个纯「理工」专业**
（工商管理/土木工程/英语/市场营销/视觉传达设计/表演）。
而 `programmer` / `hacker` / `ai` 全部要求 `major: ["理工"]`。
**这意味着一本毕业生在专业对口门控下被系统性挡在高薪理工职业之外** ——
这是比补习更值得关注的数值结构问题。

**晋升公式**（`careerTick`，`career.js:515-526`）：
```
score = 30 + LOY×0.35 + INT×0.22 + NET×0.16 + WILL×0.14
      + years×2.2 + (salaryK−1)×22 + rand(−11,13)
      − STRESS×0.18 − (ETH<35 ? 6 : 0) − risk×2
need  = 50 + level×16
```
补习在这里的净贡献：`INT +17 × 0.22 = +3.7`，`(salaryK−1)×22` 从 +0.9 → +4.4（**+3.5**），
`STRESS +25 × 0.18 = −4.5`（**代价**）→ 净值约 **+2.7 ~ +3.7** 分。

## 7. 补习的代价：几乎为零

| 画像 | cramCap | HP 中位 | STRESS 中位 |
|---|---|---:|---:|
| steady | 0 | 113.4 | 3.0 |
| steady | 10 | 108.3 | 3.0 |
| steady | 20 | 102.9 | 3.0 |
| steady | 30 | 99.3 | 3.0 |
| steady | 40 | 101.6 | 3.0 |
| steady | 100 | 100.2 | 3.0 |

**HP 掉约 13 点后不再继续，STRESS 完全看不出累积。**
`cramSchool` 的即时惩罚是 `HP −3 / STRESS +5`，但年度结算会把 STRESS 回落掉，
**30 岁的快照上不存在长期健康代价**。

对照晋升公式里的 `− STRESS × 0.18`：若 STRESS 真能累积到 45+，才会产生 −8 分左右的晋升惩罚。
现在的设计里，**补习是「有收益、无代价」的**。

## 8. 给 design-strategist 的可执行结论

### 8.1 先纠正一个方向性错误

**不要削弱或废除补习系统。** 它当前是**正收益**（+25% ~ +45%），
「补习导致收入腰斩」是测量工具的混淆，不是游戏行为。

### 8.2 真正的设计缺陷：机制问题，不是数值问题

| # | 问题 | 证据 | 建议方向 |
|---|---|---|---|
| **D-1** | **收益一次性跳变，之后归零** | study 0→15 拿到全部收益的 85%+；15→31 收益为 0。因为跨过 211 线（546）后，985 线（616）还差 70 分，够不着 | 把「跨档线」的离散收益改成**连续的**收益，或在 211~985 之间补一档；或让 study 直接影响入职起点/晋升速度，而不只走高考分 |
| **D-2** | **补习没有长期代价** | HP −3 / STRESS +5 在年度结算被抹平，30 岁快照看不出累积 | 给「长期熬夜」设计**累积惩罚**（如 `flags.cram_burnout`），让高频补习在中年后付出健康/心情代价，形成真实的取舍 |
| **D-3** | **一本毕业被专业对口锁死理工职业** | 一本专业池无纯理工；`programmer`/`hacker`/`ai` 全要求理工 | 这是比补习更值得先修的结构问题。可考虑：放宽对口为「降权」而非「禁止」，或给一本/二本一条转行通道 |
| **D-4** | **explorer 画像收入噪声过大** | 三轮复跑中位数摆动 30.8%，远超处理效应 | 任何以 explorer 为主体的收入结论都不可靠，回归用例应改用 steady 或固定职业 |

### 8.3 建议 quality-lead 修正的一行代码

```js
// production/phase6-polish/qa/scripts/regression-run.js:370-374
const pool = ['steady', 'explorer'];
for (let i = 0; i < n; i++) {
-  const pn  = pool[i % pool.length];     // ← 与 cap 完全共线
-  const cap = (i % 2 === 0) ? 0 : 40;
+  // 正交设计：画像与处理各占一个自由度
+  const pn  = pool[i % pool.length];
+  const cap = (Math.floor(i / pool.length) % 2 === 0) ? 0 : 40;
```

或更稳妥：把循环摊平成 `for (pn of pool) for (cap of [0,40]) for (i of range(n))`。

## 10. 诚实说明（这份调查的边界）

1. **效应量的区间偏宽（+25% ~ +45%）**。三个口径分别是 2×2 因子的 +25.2%/+25.0%、
   剂量实验的 +44.9%、三轮复跑的 +33.0%。差异来自基线不稳定
   （`steady@0` 三轮是 4.60/3.34/3.85 亿）。**方向和量级是稳的，精确数值请勿直接写进 spec。**
2. **`explorer` 这条臂的所有收入数字都不可靠**（三轮摆动 30.8%），
   本报告里涉及 explorer 的数字仅用于说明「画像效应」，不作为补习效应证据。
3. **子渠道分解（第 6 节）属推断，不是独立验证**。我验证了
   「收益流经 `base` 与 `kEdu`」这条**结论**，但「跨大学档线」与「职业落点改善」
   各占多少，是用静态配置表（录取线、专业池、门槛）推断的，没有做阻断实验。
4. **未验证补习对「人生满意度 / 心情 / 关系」等软指标的影响**，本报告只看 30 岁收入。
5. 全程**只读**，未修改任何游戏代码。
