人生模拟 中国 · 1955–2005

人生模拟

从城中村到江景大平层 · 也可能从写字楼到外卖站

每一次「出生」，你都会被随机投胎到某个中国家庭、某个年代——
1958 年出生的人童年在粮票与厂房里，1998 年出生的人童年在网吧与手机里。
中考、高考、找工作、谈恋爱、买房、贷款、炒股、养一只狗。
每一步都要做选择——这一局投胎差了？点一下，下一世重新来过。

  • 随机投胎：出生年份（1955–2005）、家庭、天赋、姓名每局都随机。出身共 24 种——城中村、县城双职工、农村、渔村、矿区、部队大院、铁路子弟、林场、个体户、拆迁户、教师家庭、科研院所、医生世家、文工团、体制内、侨眷、下岗职工、出租车司机、低保户、留守儿童、单亲、侨乡，一直到福利院孤儿。年份决定你这一世会亲身经历哪些年代大事——物价闯关、下岗潮、入世、股改、6124 点、股灾、疫情。
  • 升学：15 岁中考（满分 400）、18 岁高考（满分 700）——先考 5 道常识题，再和平时分一起放榜，分档进高中 / 大学。卷面 = 常识题 20% + 三年平时成绩 80%，天资足够 + 五题全对 = 真正的满分。分数由智力、意志、学习投入、常识发挥共同决定——可以「熬夜刷题」，也可以早恋（会扣分）。
  • 大学与专业：录取后要填志愿选专业，不同大学专业不同；专业决定你能进哪一行——学医才能穿白大褂，学计算机才能写代码。毕业时要选：直接找工作 / 考研 / 休整一年。考研有成功率，可能落榜。
  • 职业与晋升：毕业后在「工作」页找活干。24 种职业（程序员、产品经理、idol、主播、外卖骑手、群演、公务员、医生、律师、黑客、创业者……），每种都有 4–6 级职级阶梯。学历越高起步职级越高，绩效好会升职，混日子会降职甚至被裁。
  • 恋爱与婚姻：同学里可以早恋，成年后能偶遇（一年可能遇上好几个人），也可以花钱托人相亲。同一个对象一年最多见 3 次，聊天 / 约会 / 送礼都能涨好感，点名字就是聊天；好感够 70 且年满 22 岁可以求婚——对方家境越好，对你的存款要求越高。亲密关系分两种：普通亲密有怀孕风险，「做好措施」那一项几乎不会怀孕（要花一点钱）。未婚怀孕会重挫道德与声望，你要在「生下来 / 奉子成婚 / 打掉」之间做选择。
  • 结婚不是终点：结婚后依然会遇见别人——那一步叫越界，道德与安全感的代价很重，还有可能被撞破（断了 / 坦白 / 离婚 三条路）。感情长期不经营会冷下来，冷到一定程度会爆发婚姻危机。你也可以在「人际 → 恋人」里主动提出离婚：分家产、争抚养，换回一个人的生活。
  • 同学不会失联：小学、初中、高中、大学的每一班同学都会一直留在通讯录里，标着是哪一阶段的（毕业的就挂着一个 🎓）。老同学还能约饭、还能追——只是涨得慢一些。「一键叙旧」会把在联系的人都走一遍。
  • 上学和工作二选一：还在念书就去应聘，会先弹窗告诉你这意味着退学（之后再没有中考高考）；已经在工作却要去上大学 / 考研，同样要先辞职。两条路不可同时占着。
  • 同学与校园：大学期间每年还能选一项校园活动：泡图书馆、聚餐喝酒、社团、实习、兼职、通宵打游戏、考研、校园创业、谈恋爱、健身。
  • 父母分开互动：父亲和母亲是两个人，各有姓名、职业与身体，各自老去、各自离开。任何一位（或朋友、宠物、配偶）离世都会让你陷入悲伤，压住心情与健康。
  • 家里那本账是活的：父母每年有收入、有开销、要付利息、会还债，也会出事——加班、下岗、住院、被骗、拆迁、往你包里塞钱……家庭账簿每年都在变，撑不住的时候还会开口找你要钱。「工作」页和「人际 → 家人」都能看到。
  • 疾病会要命：健康越低越容易被病找上门。生病会强制弹出「硬扛 / 去诊所 / 住院」三选一——扛着会一年年恶化（初期 → 中期 → 重度 → 危重），拖到危重又没钱治，真的会病死。也可以随时在「工作 → 身体」里花钱就医。
  • 寿命有限：没有人能一直活着。健康、心情和年纪共同决定你能走多远，105 岁是这条路的尽头。
  • 核心属性只有 6 项：健康 / 心情 / 智力 / 魅力 / 意志 / 道德，一眼看完；其余的点属性条末尾的「＋更多」展开。18 个成就徽章会在达成时弹出（买房、结婚、抱孙辈、净资产破亿、活到 100 岁……），结局页会汇总。「工作」页还有一年一张的彩票，头奖概率千分之一。
  • 三选一：13 岁后的每个事件都有 3 个选项，文案会跟着事件内容变化（学习的事就给你学习的选项）。风险越高，收益与后果同时放大，还带概率赌注。
  • 贷款：助学贷、消费贷、信用贷、经营贷、抵押贷，还有会吃人的网贷。借钱一时爽，逾期会砸掉征信和名声，欠款会滚雪球。
  • 未成年不用愁钱：18 岁之前，生活与学费由家里承担，你不会背债。父母的家底（资产 / 负债）在「工作」页和「人际 → 家人」里随时可查。
  • 遗产继承：父母离世时三选一——全额继承／限定继承／放弃继承。
  • 市场：20 岁后可买房（可贷款）、买车、买金条土地商铺比特币，还能炒股——12 只股票随年代涨跌，遇互联网泡沫、6124 点、股灾、疫情会剧烈波动。
  • 天赋：共 124 种天赋。开局随机抽 12 张，用 10 点自由搭配；也可以点「浏览全部」看完所有天赋并按关键词搜索。负面天赋会返还点数。前世记忆能看到投资机会的未来提示。
  • 越轨有代价：婚外情会怀孕、会生下私生子。你越有名、圈层越高，越容易被曝光——配偶可能起诉离婚强行分割财产，也可能有条件原谅、睁一只眼闭一只眼，甚至让你社会性死亡。
  • 常识自洽：多套房产要交累进房产税与空置税；出狱后当不了教师、医生、公务员、飞行员；配偶会藏私房钱、主动提离婚；子女成年后会啃老、争产；男人过了 65 也很难再有孩子。
  • 存档：每步自动缓存到本机，另有 3 个手动槽，可导出 / 导入存档码跨设备继续。
  • 结局：没有唯一的终点——亿万富豪、收租的房东、股神、家族绵延、平凡的程序员……16 种以上结局，看你这一世怎么过。
