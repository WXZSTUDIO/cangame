# 人生模拟 · 中国人生重开模拟器

> 文字版人生模拟游戏。每一次「出生」，你都会被随机投胎到某个中国家庭、某个年代——
> 1958 年出生的人童年在粮票与厂房里，1998 年出生的人童年在网吧与手机里。
> 中考、高考、找工作、谈恋爱、买房、贷款、炒股、养一只狗，从 0 岁活到 100 岁以上。
> 这一局投胎差了？点一下，下一世重新来过。

在线开玩：**https://wxzstudio.github.io/cangame/**　·　当前版本 **v5.4.0**

## 玩法

| 系统 | 说明 |
| --- | --- |
| 随机投胎 | 出生年份（1955–2005）、家庭、天赋、姓名每局随机。**24 种中国国情出身**：城中村、县城双职工、农村务农、县城个体户、教师家庭、体制内干部、拆迁户、私企老板、单亲母亲、福利院孤儿、矿区、林场、军属、知青返城、医生世家、铁路职工、渔村、牧区、侨眷、建筑包工头、菜贩、出租车司机、乡镇教师、留守 |
| 年代事件 | 22 个时代事件按公历年份窗口触发：物价闯关、农田基建、石油危机、改革开放、下岗潮、入世、股改、6124 点、股灾熔断、疫情、AI 时代……窗口开启的年份必触发一个 |
| 中考 / 高考 | 15 岁中考分档进**市重点 / 普通高中 / 艺术高中·艺校 / 职高中专 / 辍学**（放榜时**列出全部学校**，进不去的写明差多少分）；18 岁高考分档上**985 / 211 / 一本 / 二本 / 专科 / 落榜**。分数由智力、意志、学习投入、家里能否供补习共同决定。1977 年前出生的人走「推荐制」，看家庭出身 |
| 刷题与早恋 | 初中高中每年可「熬夜刷题」累积学习投入（会遗忘）；和同学早恋会加分（关爱）也扣分（高考） |
| 专业对口 | 大学录取后填志愿：**61 个专业 / 9 个方向**（理工、经管、医学、法律、教育、艺术、传媒、体育、农林），每个专业都写明出路。16 个职业有专业对口要求，毕业求职**优先落到对口岗位** |
| 毕业自己选路 | 毕业当年**不再被自动安排工作**：先走「考研 / 放弃考研去投简历 / 休整一年」；考研落榜还有「二战 / 认了去工作」二选一，二战也可能再落榜 |
| 同学与校园 | **小学 / 初中 / 高中 / 大学 / 研究生**各有一班同学，逐个互动或「一键和全班互动」，毕业后转为「老同学」**永不失联**。大学每年可参加一项校园活动：泡图书馆、聚餐喝酒、社团、实习、兼职、通宵打游戏、考研、校园创业、谈恋爱、健身 |
| 职业与晋升 | 24 种职业（程序员、产品经理、idol、主播、外卖骑手、群演、电竞、公务员、教师、医生、律师、投行、AI 算法、黑客、创业者……），每种 4–6 级职级阶梯。**学历越高起步职级越高**；绩效由口碑、智力、人脉、工龄决定，好则升职，差则降职甚至被裁 |
| 恋爱与婚姻 | 三条来源：同学里追求、成年后偶遇、花钱托人相亲。聊天 / 约会 / 送礼涨好感，好感 80 且年满 22 岁可求婚（对方家境越好，对你的存款要求越高）。**未婚怀孕**会重挫道德与声望，需要在「生下来 / 奉子成婚 / 打掉」之间选择 |
| 婚姻要经营 | 配偶卡有**陪伴 / 约会 / 送礼**三种互动，都能真的把感情涨回来；一年冷落只掉 1–3 点。常年不经营感情会触发婚姻危机；也可以主动**提出离婚**，分家产、分孩子，前任会一直留在家人页 |
| 外遇与偷情 | 婚后（恋爱中）可在外面认识人：一次性「越界」，或发展成**长期偷情**——每年都有被撞破的风险，撞破后三选一：断干净 / 坦白 / 离婚再娶。也可以主动「收手」 |
| 会被表白 | 不是永远只有你在追：单身、恋爱中、甚至已婚，都可能有人主动向你表白，三选一接住 / 装傻 / 认真回绝 |
| 亲密可以很安全 | 亲密关系有「做好措施」选项，150 元把怀孕概率压到 0.8%，代价是不能白嫖 |
| 会要命的病 | 健康低于警戒线就容易被病找上门：感冒、胃溃疡、骨折、肝炎、抑郁、高血压、心脏病、中风、癌症。得病后是**强制事件**，三选一硬扛 / 去诊所 / 住院。**不治会逐年恶化：初期 → 中期 → 重度 → 危重，到危重真的会带走你** |
| 家里的账是活的 | 父母各有职业与健康，每年有收入、有开销、有利息、有还债，也会出事（加班受伤、下岗、拆迁、生病、中奖、背债……）。债务压顶时会来找你要钱。「人际 → 家人」页有完整账簿卡 |
| 父母分开 | 父亲和母亲是两个人，各自有名有姓、有职业、有健康、各自老去、各自离开，互动收益也不同 |
| 寿命与悲伤 | 没有人能一直活着：健康、心情与年纪共同决定寿命，105 岁是尽头。亲人 / 朋友 / 宠物 / 配偶离世会让你陷入**悲伤**，压住心情、健康与压力 |
| 三选一 | 13 岁后的每个事件都有 3 个选项，**文案跟着事件内容变化**（学习的事给学习的选项，酒局的事给酒局的选项）。风险越高，收益与后果同时放大，并附带概率赌注 |
| 贷款 | 助学贷、消费贷、信用贷、经营贷、抵押贷，以及会吃人的网贷。额度看收入与征信，逾期会砸掉征信与名声，欠款滚雪球 |
| 市场 | 20 岁后随时进入：房产 11 种（可贷款 / 押一付三租房）、汽车 8 种、金条字画商铺比特币等资产 9 种、A 股风格股票 12 只 |
| 股市 | 价格随年代演进，遇互联网泡沫(2000)、6124 点(2007)、金融危机(2008)、四万亿(2009)、股灾(2015)、熔断(2016)、疫情(2020)、AI 行情(2023) 等时代冲击；有分红、手续费、走势条（涨红跌绿） |
| 未成年免负债 | 18 岁之前生活与学费由家里承担，个人不会背债；家里账簿（资产 / 负债）按出生年代缩放，「工作」页与「人际 → 家人」随时可查 |
| 遗产继承 | 父母离世时三选一：**全额继承**／**限定继承**／**放弃继承**。未成年时由亲戚处理后事并勾销债务 |
| 天赋 | **124 种天赋**，开局抽 12 张，用天赋点自由搭配；可「浏览全部 + 关键词搜索 + 换一批」；负面天赋会返还点数 |
| 成就与彩票 | 18 个成就徽章（买房、生子、百岁、中大奖……），解锁时弹徽章、结局页有成就墙；12 岁后每年可买一张彩票，头奖概率千分之一 |
| 核心属性 | 顶栏只显示 6 项核心属性：**健康 / 心情 / 智力 / 魅力 / 意志 / 道德**，异常时标红；压力、体力、人脉、声望、口碑等次要属性点「＋ 更多」展开 |
| 韩式证件照 | 父母、配偶、前任、同学、朋友、恋人各有**一张由名字决定的脸**（发型 / 肤色 / 穿搭 / 耳饰各不相同），并随年龄变化：少年有腮红、中年戴眼镜、老年白发与皱纹 |
| 他们会来找你 | 父母、配偶、恋人、朋友、同学每年都可能**主动发起一次邀约**（回家吃饭 / 约会 / 同学聚会…），三选一回应，答应对方好感真的会涨 |
| 向善 | 道德不是只能往下掉：「人际 → 向善」页有 8 件可以主动做的事（还钱包、福利院、道歉、志愿者、戒坏习惯、献血、匿名捐款、山区支教），每件一年一次 |
| 星探 | 初中 / 高中颜值够高（或念艺术高中）就可能被星探拦下：签约即**退学进练习室**，也可以要一笔签约金赌一把，或者把书念完 |
| 前世记忆 | 核心天赋。带此天赋时，投资机会会显示「未来的提示」——黄金、学区房、比特币 |
| 结局 | 16 种结局，从「亿万富豪」「股神」「收租的房东」「家族绵延」到「平凡的程序员」「负债者」，按净资产、声望、人脉与关键选择判定 |

### 存档

- **自动缓存**：每一步自动写入浏览器 localStorage，关掉网页也能「继续人生」
- **手动存档槽**：3 个独立槽位，可随时覆盖 / 读取 / 删除
- **存档码**：导出为一段文本（Base64），换设备粘贴即可导入继续

快捷键：`空格` / `回车` 在只有一个选项时自动推进。

## 目录结构

```

├── index.html          # 页面结构（标题 / 捏人 / 游戏 / 市场 / 结局）
├── assets/
│   ├── style.css       # 样式（手绘纸质卡通主题，移动端自适应）
│   ├── data.js         # 天赋 124 · 出身 24 · 事件 241 · 投资 11 · 结局 16 · 疾病 9 · 成就 18 · 家庭事件 18
│   ├── market.js       # 房产 11 · 汽车 8 · 资产 9 · 股票 12 · 年代指数与危机冲击
│   ├── engine.js       # 状态机 / 事件与三选项 / 概率赌注 / 投资与贷款结算 / 疾病与家庭账簿 / 结局判定
│   ├── school.js       # 中考高考 / 高中与大学 / 小学起的同学 / 校园活动
│   ├── career.js       # 24 种职业与职级阶梯 / 求职门槛 / 年度晋升评定
│   ├── love.js         # 恋爱来源 / 好感互动 / 求婚结婚 / 出轨与离婚 / 怀孕与生育
│   ├── loan.js         # 6 类贷款产品 / 额度与征信 / 逾期滚动
```

纯静态、零依赖、零构建，双击 `index.html` 即可离线游玩。

## 部署

仓库 `cangame` 为源码主仓库；线上版本同步在 `wxzstudio.github.io/cangame/`，
由 GitHub Pages 直接托管静态文件，推送即生效。

改完代码后一条命令同步两个仓库（走本机 git 凭据，不需要令牌）：

```bash
python tools/deploy.py                      # 只推有变动的文件
python tools/deploy.py --msg="修复投资结算"   # 自定义提交信息
```

首次运行会在 `.sync/` 建立缓存克隆，之后增量推送；`.sync/` 已在 `.gitignore` 中忽略。
