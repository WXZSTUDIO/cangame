# 人生模拟 · 中国人生重开模拟器

> 文字版人生模拟游戏。每一次「出生」，你都会被随机投胎到某个中国家庭、某个年代——
> 1958 年出生的人童年在粮票与厂房里，1998 年出生的人童年在网吧与手机里。
> 中考、高考、找工作、谈恋爱、买房、贷款、炒股、养一只狗，从 0 岁活到 100 岁以上。
> 这一局投胎差了？点一下，下一世重新来过。

在线开玩：**https://wxzstudio.github.io/cangame/**

## 玩法

| 系统 | 说明 |
| --- | --- |
| 随机投胎 | 出生年份（1955–2005）、家庭、天赋、姓名每局随机。10 种中国国情出身：城中村、县城双职工、农村务农、县城个体户、教师家庭、体制内干部、拆迁户、私企老板、单亲母亲、福利院孤儿 |
| 年代事件 | 22 个时代事件按公历年份窗口触发：物价闯关、农田基建、石油危机、改革开放、下岗潮、入世、股改、6124 点、股灾熔断、疫情、AI 时代……窗口开启的年份必触发一个 |
| 中考 / 高考 | 15 岁中考分档进**市重点 / 普通高中 / 职高中专 / 辍学**；18 岁高考分档上**985 / 211 / 一本 / 二本 / 专科 / 落榜**。分数由智力、意志、学习投入、家里能否供补习共同决定。1977 年前出生的人走「推荐制」，看家庭出身 |
| 刷题与早恋 | 初中高中每年可「熬夜刷题」累积学习投入（会遗忘）；和同学早恋会加分（关爱）也扣分（高考） |
| 同学与校园 | 初中 / 高中 / 大学各有一班同学，逐个互动或「一键和全班互动」。大学每年可参加一项校园活动：泡图书馆、聚餐喝酒、社团、实习、兼职、通宵打游戏、考研、校园创业、谈恋爱、健身 |
| 职业与晋升 | 24 种职业（程序员、产品经理、idol、主播、外卖骑手、群演、电竞、公务员、教师、医生、律师、投行、AI 算法、黑客、创业者……），每种 4–6 级职级阶梯。**学历越高起步职级越高**；绩效由口碑、智力、人脉、工龄决定，好则升职，差则降职甚至被裁 |
| 恋爱与婚姻 | 三条来源：同学里追求、成年后偶遇、花钱托人相亲。聊天 / 约会 / 送礼涨好感，好感 80 且年满 22 岁可求婚（对方家境越好，对你的存款要求越高）。**未婚怀孕**会重挫道德与声望，需要在「生下来 / 奉子成婚 / 打掉」之间选择 |
| 父母分开 | 父亲和母亲是两个人，各自有名有姓、各自老去、各自离开，互动收益也不同 |
| 寿命与悲伤 | 没有人能一直活着：健康、心情与年纪共同决定寿命，105 岁是尽头。亲人 / 朋友 / 宠物 / 配偶离世会让你陷入**悲伤**，压住心情、健康与压力 |
| 三选一 | 13 岁后的每个事件都有 3 个选项，**文案跟着事件内容变化**（学习的事给学习的选项，酒局的事给酒局的选项）。风险越高，收益与后果同时放大，并附带概率赌注 |
| 贷款 | 助学贷、消费贷、信用贷、经营贷、抵押贷，以及会吃人的网贷。额度看收入与征信，逾期会砸掉征信与名声，欠款滚雪球 |
| 시장 市场 | 20 岁后随时进入：房产 11 种（可贷款 / 押一付三租房）、汽车 8 种、金条字画商铺比特币等资产 9 种、A 股风格股票 12 只 |
| 股市 | 价格随年代演进，遇互联网泡沫(2000)、6124 点(2007)、金融危机(2008)、四万亿(2009)、股灾(2015)、熔断(2016)、疫情(2020)、AI 行情(2023) 等时代冲击；有分红、手续费、走势条（涨红跌绿） |
| 未成年免负债 | 18 岁之前生活与学费由家里承担，个人不会背债；家里账簿（资产 / 负债）按出生年代缩放，「工作」页与「人际 → 家人」随时可查 |
| 遗产继承 | 父母离世时三选一：**全额继承**／**限定继承**／**放弃继承**。未成年时由亲戚处理后事并勾销债务 |
| 天赋 | 开局抽 10 张天赋，用 10 点天赋点自由搭配；负面天赋会返还点数 |
| 前世记忆 | 核心天赋。带此天赋时，投资机会会显示「未来的提示」——黄金、学区房、比特币 |
| 结局 | 16 种结局，从「亿万富豪」「股神」「收租的房东」「家族绵延」到「平凡的程序员」「负债者」，按净资产、声望、人脉与关键选择判定 |

### 存档

- **自动缓存**：每一步自动写入浏览器 localStorage，关掉网页也能「继续人生」
- **手动存档槽**：3 个独立槽位，可随时覆盖 / 读取 / 删除
- **存档码**：导出为一段文本（Base64），换设备粘贴即可导入继续

快捷键：`空格` / `回车` 在只有一个选项时自动推进。

## 目录结构

```
cangame/
├── index.html          # 页面结构（标题 / 捏人 / 游戏 / 市场 / 结局）
├── assets/
│   ├── style.css       # 样式（手绘纸质卡通主题，移动端自适应）
│   ├── data.js         # 天赋 24 · 出身 10 · 事件 233 · 投资 11 · 结局 16 · 选项文案模板
│   ├── market.js       # 房产 11 · 汽车 8 · 资产 9 · 股票 12 · 年代指数与危机冲击
│   ├── engine.js       # 状态机 / 事件与三选项 / 概率赌注 / 投资与贷款结算 / 结局判定
│   ├── school.js       # 中考高考 / 高中与大学 / 同学 / 校园活动
│   ├── career.js       # 24 种职业与职级阶梯 / 求职门槛 / 年度晋升评定
│   ├── love.js         # 恋爱来源 / 好感互动 / 求婚结婚 / 怀孕与生育
│   ├── loan.js         # 6 类贷款产品 / 额度与征信 / 逾期滚动
│   └── ui.js           # 渲染 + 市场交易 + 人际面板 + 存档（localStorage）
└── tools/              # 离线模拟 / jsdom / 线上冒烟测试脚本
```

纯静态、零依赖、零构建，双击 `index.html` 即可离线游玩。

## 部署

仓库 `cangame` 为源码主仓库；线上版本同步在 `wxzstudio.github.io/cangame/`，
由 GitHub Pages 直接托管静态文件，推送即生效。

改完代码后一条命令同步两个仓库（走本机 git 凭据，不需要令牌）：

```bash
python tools/deploy.py                      # 只推有变动的文件
python tools/deploy.py --msg="修复投资结算"   # 自定义提交信息
```

首次运行会在 `.sync/` 建立缓存克隆，之后增量推送；`.sync/` 已在 `.gitignore` 中忽略。
