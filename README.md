# 江南逆袭 · 강남 역습

> 文字版韩国人生模拟游戏。1985 年，你出生在首尔江南区一间看不见天空的半地下室；
> 你带着前世的记忆醒来，知道自己会在某一年死在汉江边。
> 这一世，你能否从 반지하（半地下室）走到太星集团会长办公室的落地窗前？

在线开玩：**https://wxzstudio.github.io/cangame/**

---

## 玩法

| 系统 | 说明 |
| --- | --- |
| 推进 | 点击「下一年」，每年触发 1–2 个事件，改变智力 / 体魄 / 魅力 / 意志 / 健康 / 压力，以及资产、人脉、声望 |
| 天赋 | 开局抽 10 张天赋，用 10 点天赋点自由搭配；负面天赋会返还点数 |
| 出身 | 8 种家庭背景（半地下室、工厂家庭、单亲、孤儿院、教授家庭、太星远亲…）决定起跑线 |
| 前世记忆 | 核心天赋。带此天赋时，投资机会会显示「未来的提示」——IMF、江南房价、比特币 |
| 投资 | 特定年份出现投资机会，可投入身家的 30% / 60% / 全部，数年后一次性结算（前世记忆显著提高收益下限） |
| 财阀线 | 声望与人脉达标后进入太星集团，触发继承之争、秘密账本、股权收购、股东大会等多段剧情 |
| 结局 | 12+ 种结局，从「财阀之主」「复仇的设计者」到「温暖的店」「负债者」，按资产、声望、人脉与关键选择判定 |

### 存档

- **自动缓存**：每一步自动写入浏览器 localStorage，关掉网页也能「继续人生」
- **手动存档槽**：3 个独立槽位，可随时覆盖 / 读取 / 删除
- **存档码**：导出为一段文本（Base64），换设备粘贴即可导入继续

快捷键：`空格` / `回车` 在只有一个选项时自动推进。

## 目录结构

```
cangame/
├── index.html          # 页面结构（标题 / 捏人 / 游戏 / 结局）
├── assets/
│   ├── style.css       # 样式（深色 + 金色财阀感，移动端自适应）
│   ├── data.js         # 天赋 24 · 出身 8 · 事件 101 · 投资 11 · 结局 13
│   ├── engine.js       # 状态机 / 事件抽取 / 投资结算 / 结局判定
│   └── ui.js           # 渲染 + 存档（localStorage）
└── tools/              # 离线模拟测试脚本（不参与部署）
```

纯静态、零依赖、零构建，双击 `index.html` 即可离线游玩。

## 本地运行

```bash
python -m http.server 8000   # 然后打开 http://localhost:8000
```

## 部署

仓库 `cangame` 为源码主仓库；线上版本同步在 `wxzstudio.github.io/cangame/`，
由 GitHub Pages 直接托管静态文件，推送即生效。

改完代码后一条命令同步两个仓库（走本机 git 凭据，不需要令牌）：

```bash
python tools/deploy.py                      # 只推有变动的文件
python tools/deploy.py --msg="修复投资结算"   # 自定义提交信息
```

首次运行会在 `.sync/` 建立缓存克隆，之后增量推送；`.sync/` 已在 `.gitignore` 中忽略。
