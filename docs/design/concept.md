# cangame v3 · 概念文档（XBA 风格篮球经理页游）

> 第三次整库覆盖。前两代（人生模拟器 v6.5 / 4 阵营博弈 v2）已归档 `legacy/` 与 `legacy/v2-faction/`。本文件为产品概念的单一事实来源，供策划、美术、工程共享。

## 1. 一句话定义
玩家扮演一支虚构篮球联赛球队的**总经理兼主教练**：排兵布阵、打满一个赛季、做交易与养成，目标是在不破产的前提下拿到总冠军。

## 2. MDA 框架
- **Mechanics（机制）**：名册管理、能力值/合同、训练与体力、战术板布阵、回合制比赛模拟、转会市场、选秀/青训、工资帽与财务。
- **Dynamics（动态）**：球员状态随年龄/训练/伤病波动；战术克制让"以弱胜强"可复现；工资帽逼你在明星与深度间取舍；赛季长河里连败会触发信任危机。
- **Aesthetics（美学）**：**执教感（challenge）** + **经营算计（discovery）** + **爆冷爽感（sensation）**。核心情绪是"我在场边真正做了决定"。

## 3. 玩家心理学三要素
- **自主（Autonomy）**：每场前自己拖点位布阵、选战术、决定轮换 —— 不是自动比赛。
- **胜任（Competence）**：战术克制矩阵 + 球员对位让"我读懂了局面并做对"可被感知；数据面板给即时反馈。
- **关联（Relatedness）**：联赛 30 队有叙事（ rival、新秀崛起、老将谢幕）；玩家与"自己的球队"建立归属。

## 4. 设计支柱（取舍时引用）
1. **执教优先于管理**：任何经营系统不能盖过"布阵+比赛"的核心爽点。
2. **单局短、赛季长**：一场比赛 90 秒内看完，一个赛季几十次点击走完。
3. **确定性可复现**：同种子同结果，可存档、可调试、可平衡。
4. **零版权、零后端**：全虚构、纯前端、Pages 直部署。
5. **数据即美术**：战术板用真实坐标与粉笔线呈现，不靠装饰图。

## 5. 核心循环
```
选队 → 看名册/状态 → 拖战术板布阵 + 选战术 → [下一场] 比赛 play-by-play 模拟
     → 赛后数据/信任度 → 自由经营（训练/交易/签约）→ 回到选队
```
一个赛季的节奏曲线：常规赛（长、平淡、攒排名）→ 交易截止日（拐点）→ 季后赛（高压、每场分量重）→ 休赛期（选秀/续约，重置期待）。

## 6. 目标用户与主要任务
- 用户：喜欢体育经营、策略、数字的休闲玩家；原 XBA / 篮球营收玩家。
- **主要任务（80% 时间）**：布阵 + 选战术 + 看比赛结果 + 微调阵容。养成与交易是"两场比赛之间的甜点"，不是主菜。

## 7. 范围分层
- **v1 必做（本 Sprint 链）**：联赛生成（30 队）、名册与能力/合同、训练与体力、战术板（拖点位+战术）、比赛引擎（play-by-play）、赛程日历推进、积分榜、季后赛、冠军结算、财务面板（收支持平即可）。
- **v1 不做（后续 Sprint）**：深度转会谈判 AI、青训营养成树、球探系统、伤病长期恢复、 multiplayer/联机。
- **后续**：真实感架空（城市名）、球员交易卡牌化、生涯模式多赛季连续。

## 8. 与 XBA 的差异化
| XBA | 我们（v3） |
|---|---|
| 重社交、联盟、实时 | 纯单机、随时可停 |
| 数值深、学习曲线陡 | 核心三角轻量、首局即玩 |
| 长养成、多赛季 | 单赛季闭环、重开即新局 |
| 商业运营重 | 财务只做"别破产"的张力 |

**我们放弃**：社交攀比、超深数值养成的长期粘性。
**我们换回**：零门槛、单局爽、离线可玩、独立开发者可维护。

## 9. 风险与建议（不改动已定决策）
- 比赛引擎若完全随机会"不像篮球"：必须让能力值显著拉开命中率差（见 numbers.md 的 SHO_COEF）。
- 82 场常规赛对页游偏长：建议"一键快进整轮"或默认缩短到 58–66 场（已设 REGULAR_ROUNDS 可调）。
- 战术板拖拽在移动端需降级为"点选 5 个点位"：UI 必须实现非拖拽回退路径。
- 工资帽与财务若太复杂会违反支柱 1：v1 财务只做"收入-支出-工资帽超限警告"，不做税务细账。
