## 一、概述

S13 是玩家唯一接触到的东西。核心约束是：**Chalkboard 视觉方向留白多、质感强，但我们的信息密度很高**（13 人名册 + 12 项属性 + 4 个战术维度 + 数据条）。

### v1 最小可玩版本长什么样

- **主界面**：左半场战术板（可拖点位）+ 右侧常驻数据条 + 右下抽屉（名册/训练/市场/财务/排名）。
- **赛后页**：pbp 文本流 + box score。
- **休赛期页**：6 步引导。
- 关键操作 ≤ 3 次点击；「进行下一轮」是最大最显眼的 CTA。
- **不做**：移动端适配、动画转场、音效、多主题、拖拽排序名册。

> 设计支柱引用：**P3 阵容即战术**（拖拽必须顺手）、**P1 一轮一决策**（调整路径要短）。

```js
### 2.2 主界面（阵容与战术板）三层信息架构

```

   左（1fr）：半场 SVG 480×480，5 个可拖点位 + 下方 5 张席位卡（与点位双向联动）
   右（320px）：战术选项（进攻 5 / 防守 5 两组 chip）+ 节奏滑杆 + 预期效率能力条

```
> 落在界面 3；界面 1（赛季主页）保留 CTA 与数据条，保证「不进战术板也能推进赛季」。
```

## 三、规则

1. **布局**：桌面 `≥ 1024px`，左侧战术板占 58%，右侧数据条 42%。低于 1024px 显示「请使用桌面浏览器」提示（v1 不做移动端）。
2. **CTA 位置**：「▶ 进行下一轮」固定在战术板正下方居中，最大按钮。
3. **拖拽**：HTML5 Drag & Drop（v1 不用第三方库）。名册行 `draggable`，点位为 `dropzone`。
4. **键盘替代**：每个点位可 Tab 聚焦 → 按数字键 1-5 选择该位置的第 N 名球员（**可访问性硬要求**）。
5. **pbp 渲染**：一次性渲染全部事件（v1 不做逐条播放动画）；深灰/浅灰交替；`key=true` 高亮。
6. **快进**：显示进度条，分帧执行（每帧 ≤ 5 轮），可随时取消。
7. **自动存档**：每轮结束后写入，顶栏短暂 toast「已保存」。
8. **可访问性基线**：
   - 所有文字对比度 ≥ 4.5:1（正文）/ ≥ 3:1（大字）
   - 不依赖颜色单通道传递信息（正负、涨跌都带符号或文字）
   - 所有交互元素可 Tab 到达，有可见 focus 环
   - 玩家队/对手用文字标签区分，不只靠颜色
9. **无框架、无构建**：`ui.js` 用原生 DOM API，模板字符串拼接。
10. **所有文案中文**，无英文占位。

## 五、交互

| 元素 | 行为 | 反馈 |
|---|---|---|
| 战术板点位 | 拖入球员 → 高亮 + 轻微缩放 | 拖出 → 恢复默认填充 |
| 点位上的球员卡 | 显示 姓名 / 位置 / OVR / 体力条 | 体力 < 40 时橙色，< 20 红色 |
| 节奏滑块 | 实时显示「回合 ≈ N」「体力消耗 N×」 | 数字联动 |
| 进攻/防守下拉 | hover 显示克制矩阵该行/列全部数值 | tooltip 表格 |
| 熟练度条 | 当前战术旁小进度条 + 数字 | 换战术时显示预期损失 |
| CTA | 点击 → 禁用 → 模拟 → 跳赛后页 | 禁用期间显示「模拟中…」 |
| 快进 | 下拉选择目标 → 进度条 → 完成 | 显示「已快进 N 轮」 |
| 名册行 | 点击展开属性弹层 | 弹层可 Esc 关闭 |
| 市场出价 | 滑块 + 实时接受概率 | 概率进度条 + 数字 |
| 存档 toast | 每轮结束短暂提示 | 2 秒后消失 |

**可访问性**：
- 点位：`role="button"` + `aria-label="持球点：李昊（PG，OVR 74）"`
- 拖拽替代：Tab 聚焦点位 → 数字键选择
- 所有图表有 `<table>` 替代或 `aria-label`
- 颜色对比度由林绘澄在美术圣经里保证，本 GDD 只提要求

## 六、边界与异常

| # | 情况 | 处理 |
|---|---|---|
| E1 | 视口 < 1024px | 显示全屏提示「本作目前仅支持桌面浏览器（≥1024px）」 |
| E2 | 拖拽到非 dropzone | 拖拽取消，球员卡回弹（无副作用） |
| E3 | 拖入的球员已被交易/裁掉 | 拖拽时校验 `player.teamId`，不匹配则拒绝并 toast |
| E4 | pbp 超过 800 条 | 虚拟滚动（只渲染可视区 + 前后 50 条） |
| E5 | 快进中用户刷新页面 | 已完成的轮次已存档，刷新后从中断处继续 |
| E6 | localStorage 写失败 | 顶栏橙色警告（见 gdd/core.md E1） |
| E7 | 名册 15 人导致抽屉过高 | 抽屉内部滚动，表头 sticky |
| E8 | 属性弹层数据缺失（旧存档） | 缺失字段显示「—」，不崩溃 |
| E9 | 连续快速点击 CTA | CTA 在模拟期间 `disabled`，防重入 |
| E10 | 浏览器不支持 HTML5 DnD（老 Safari） | 降级：点位点击 → 弹出候选列表（键盘替代路径复用） |
| E11 | 单次渲染 pbp 卡顿（> 200ms） | 分批 `requestAnimationFrame` 渲染，每帧 100 条 |
| E12 | 中文文案溢出（长姓名） | CSS `text-overflow: ellipsis` + `title` 完整文本 |

6. **界面 3 的两栏比例 `1fr / 320px`、gutter 24，与她的 §6.3 一致**，本 GDD 不再另定。
